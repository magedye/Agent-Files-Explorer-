# سجل التغييرات

## 3.4.0

- إنشاء حزمة Blind Lab مستقلة وثائقيًا عن Project Hub.
- حذف Semantic Definition Registry والبطاقات والاختبارات ذات الإجابات الدلالية السابقة.
- توفير Runtime Kernel وحزم قواعد مرحلية وفهرس قواعد آمن بلا أمثلة جذرية.
- توفير مرجع صرفي بنيوي فقط بلا قيم عاملية دلالية.
- إضافة قوالب الدحض والحدود وأهلية القفل والتدقيق للتشغيلات المحجوبة.
- تعريف العمى بصدق بوصفه عزلًا وثائقيًا وجلسيًا لا محوًا للذاكرة البارامترية.
