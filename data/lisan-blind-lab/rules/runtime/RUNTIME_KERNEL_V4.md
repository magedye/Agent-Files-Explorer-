# نواة التشغيل المنهجية المختصرة — Runtime Kernel v4

**الغرض:** هذه هي الحزمة الدائمة التي تُقرأ في كل تشغيل. لا يُحمّل سجل R01–R113 كاملًا إلا عند Trigger محدد.

## المبادئ الحاجبة

1. **السيادة الدلالية القرآنية الداخلية (`QURAN-INTERNAL SEMANTIC SOVEREIGNTY`)**: لا معنى خارجي داخل المسار الدلالي.
2. **البدء من المجهول (`ZERO-PRIOR-MEANING`)**: لا Gloss موروث يعمل دليلًا.
3. **المفهوم الجذري الواحد (`SINGLE ROOT CORE`)** لهوية جذرية مؤكدة؛ الشك في الأسرة يُوسم بنيويًا.
4. **تغاير المبنى والمعنى (`FORM–MEANING COVARIANCE`)**: كل فرق بنائي يحتاج مساهمة دلالية مرشحة.
5. **corpus أولًا (`CORPUS-FIRST`)**: فهرس الأسرة قبل النواة، وتغطية صادقة.
6. **الفصل الطبقي (`LAYER SEPARATION`)**: Root/Form/Construction/Arguments/Context/Local Meaning.
7. **الملاحظة لا تساوي التفسير (`OBSERVATION ≠ INTERPRETATION`)**.
8. **المجهول نتيجة صحيحة (`UNKNOWN IS VALID`)**.
9. **الدحض والسياق الحاسم (`FALSIFICATION / DECISIVE CONTEXT`)**.
10. **النفي قبل التحديد (`NEGATIVE DETERMINATION`)** مع سجل استبعادات.
11. **التفريد اللفظي (`LEXICAL DISTINCTIVENESS`)** شرط للقفل بحسب نطاق الدعوى.
12. **القفل لا يساوي الاعتماد (`LOCK ≠ OWNER ACCEPTANCE ≠ REGISTRY ADOPTION`)**.
13. **قيمة المنهج أعلى من الجواب المحلي (`METHOD VALUE > LOCAL ANSWER`)**.
14. **الحد الأدنى الفعال من الحوكمة (`MINIMUM EFFECTIVE GOVERNANCE`)**.

## حالات التوقف الفوري

- النص/المصدر القانوني غير متاح مع ادعاء تحقق نهائي.
- Prior وثائقي متاح داخل Blind Lab.
- Corpus claim غير قابل للتدقيق.
- لا فرضية موجبة منافسة أو `C0` عند إمكان ذلك.
- تناقض جذري حقيقي مخفي.
- سياق حاسم يعتمد على Parse غير مستقر.
- معنى موضعي لا يمكن تتبعه إلى الطبقات.
- Gloss جذري يطابق لفظًا قرآنيًا قريبًا بلا تفريد.

## مخرجات التشغيل الدنيا

- حالة النص والمصادر.
- Coverage: Index / Deep / Context Diversity.
- فرضيات موجبة + `C0`.
- Semantic Exclusion Ledger.
- Falsification Matrix.
- Semantic Boundary: REQUIRED/PERMITTED/EXCLUDED/UNKNOWN.
- Lock state and blockers.
