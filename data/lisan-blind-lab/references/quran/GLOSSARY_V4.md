# المسرد المرجعي المختصر

| المصطلح | التعريف |
|---|---|
| **C0 — الفرضية الصفرية** | النموذج المنافس الذي يقول إن النواة الإيجابية لم تُثبت تحت الأدلة الحالية. لا يعني التوقف المبكر. قد ينتهي إلى `INSUFFICIENT_EVIDENCE`, `STRUCTURAL_INSTABILITY`, `ROOT_ASSIGNMENT_UNCERTAIN`, أو `NO_DISTINCTIVE_CORE_ESTABLISHED`. |
| **QAC** | `Quranic Arabic Corpus v0.4`؛ مورد annotation صرفي/بنيوي مرشح، ليس نصًا قانونيًا ولا سلطة دلالية، وتجذيره ولممه قابلة للمراجعة. |
| **على بصيرة** | مادة مشروع سابقة تحمل نتائج ومفاهيم؛ تعامل Prior محجوب قبل القفل، ومعيار مقارنة بعد القفل فقط. |
| **Root Core — المفهوم الجذري** | أصغر بنية مفهومية ثابتة تفسر الأسرة المؤكدة من دون ابتلاع مساهمة الصيغة والتركيب والسياق. |
| **Local Meaning — المعنى الموضعي** | ناتج تركيب النواة مع الصيغة والتركيب والمشاركين والسياق في موضع محدد. |
| **Decisive Context — السياق الحاسم** | سياق عالي كسب المعلومات يرفض أو يفصل فرضيات جوهرية، مع ثبات بنيوي كافٍ. |
| **C0 كـنتيجة** | تصبح نتيجةً بعد استكمال corpus policy، واختبار بدائل إيجابية حقيقية، والدحض، وعدم قدرة الأدلة الحالية على ترجيح نواة مميزة. |
| **الجذر قليل الورود** | افتراضيًا: 20 موضعًا مؤكدًا أو أقل؛ يفحص كاملًا، ما لم يقرر المالك خلاف ذلك. |
| **الجذر واسع الورود** | أكثر من 20 موضعًا مؤكدًا؛ يبدأ بفهرس كامل وعينة تحليل عميق لا تقل عن 10، وتشمل كل صيغة/تركيب/عنقود رئيسي ثم تتوسع حسب كسب المعلومات. العتبة إجرائية قابلة للمراجعة وليست حقيقة دلالية. |
| **Index Coverage** | نسبة المواضع المفهرسة بنيويًا من الإجمالي. |
| **Deep Analysis Coverage** | نسبة المواضع التي خضعت لتحليل موضعي عميق واختبار الفرضيات. |
| **Lock** | لقطة داخلية versioned، لا تعني صحة نهائية أو قبول مالك. |
