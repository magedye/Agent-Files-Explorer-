# OCD-001 — السيادة الدلالية القرآنية الداخلية

**الاسم الإنجليزي المرجعي:** `QURAN-INTERNAL SEMANTIC SOVEREIGNTY`  
**الحالة:** `OWNER-ADOPTED / CONSTITUTIONAL / ACTIVE`  
**الوزن:** `CONSTITUTIONAL / CRITICAL`  
**تاريخ الاعتماد:** 2026-08-15

## القرار

يُكتشف معنى الجذر أو اللفظ أو الصيغة أو الحرف أو التركيب القرآني ويُختبر من corpus القرآن نفسه، وفق الـProfile القانوني المعتمد.

لا يجوز أن تعمل المعاني الثقافية أو الدينية أو التفسيرية أو المعجمية أو العقدية أو الفقهية أو الأدبية أو الاصطلاحية الموروثة بوصفها:

- دليلًا دلاليًا؛
- تأكيدًا؛
- إثراءً؛
- تصحيحًا؛
- مولد فرضيات؛
- مرجحًا عند التعادل؛
- أو سببًا لرفع الثقة.

## الآثار التشغيلية

1. التفاسير ممنوعة من مسار الاكتشاف والدحض والقفل والاعتماد.
2. المعاجم والحديث والشعر والترجمات والـglosses وقوائم المرادفات والمصطلحات اللاحقة لا تدخل مسار الدلالة.
3. المعاني المتذكّرة من النموذج تعامل `PRIOR_CONTAMINATED` ولا تستخدم دليلًا.
4. يبدأ كل هدف من `UNKNOWN` مهما كان معناه الموروث مشهورًا.
5. الجار القرآني اللازم للتفريق يُحلل داخليًا؛ لا يُستورد معناه.
6. تبقى تعريفات المشروع السابقة و«على بصيرة» Priors محجوبة في Blind Lab حتى `LOCK_INTERNAL_RESULT`.
7. بعد قفل صالح يجوز مقارنة النتيجة بـPriors المشروع من دون تعديل اللقطة الأصلية.
8. يجوز بطلب صريح إعداد **مراجعة تفسيرية/تاريخية منفصلة** وفق `POST-LOCK INTERPRETIVE REVIEW POLICY`. هذه المراجعة لا تنشئ النواة ولا تثبتها ولا ترفع ثقتها. وإذا وُصف رأي بأنه مؤيد، فالاتجاه هو: النتيجة القرآنية الداخلية تؤيد الرأي، لا أن الرأي يؤيد النتيجة.

## نمط الفشل الذي يمنعه

`HERITAGE/CONVENTIONAL MEANING → IMPORTED AS EVIDENCE → QURAN-INTERNAL DISCOVERY CONTAMINATED`

## اختبارات الانحدار

- يبدأ تحليل الألفاظ المشهورة من UNKNOWN.
- لا يستخدم الجار الدلالي قبل ملف داخلي مستقل.
- لا يرفع الاتفاق مع رأي موروث الثقة الدلالية.
- إذا ظهر مصدر محظور في تشغيل أعمى يسجل `SOURCE_ACCESS_DENIED / PRIOR_CONTAMINATED` ويستبعد مضمونه.

# OCD-002 — البروتوكول الإلزامي للتحليل والعرض الدلالي الطبقي

**الاسم الإنجليزي المرجعي:** `MANDATORY LAYERED SEMANTIC ANALYSIS & PRESENTATION PROTOCOL`  
**الحالة:** `OWNER-ADOPTED / CONSTITUTIONAL / ACTIVE`  
**الوزن:** `CONSTITUTIONAL / CRITICAL`  
**تاريخ الاعتماد:** 2026-08-15

## القرار

يُعتمد الملف:

`references/quran/governance/MANDATORY_LAYERED_SEMANTIC_ANALYSIS_PRESENTATION_PROTOCOL.md`

مرجعًا وحيدًا للطبقات الكاملة. أي تعداد مختصر في README أو Runbook هو **View تشغيلي** ولا ينشئ بروتوكولًا موازيًا. لا تُحذف طبقة ناقصة؛ تعرض `UNKNOWN / INCOMPLETE / NOT YET ANALYZED`.

## نمط الفشل الذي يمنعه

`COMPRESSED LOCAL GLOSS → LAYER COLLAPSE → ROOT CORE CONTAMINATION → FALSE CONFIDENCE`

# OCD-003 — العرض العلمي العربي أولًا مع المصطلحات الثنائية

**الاسم الإنجليزي المرجعي:** `ARABIC-FIRST SCIENTIFIC PRESENTATION STANDARD`  
**الحالة:** `OWNER-ADOPTED / GOVERNANCE / ACTIVE`  
**الوزن:** `HIGH`  
**تاريخ الاعتماد:** 2026-08-15

## القرار

تكون العربية الفصحى الدقيقة هي اللغة الأساسية الكاملة في تقارير المشروع ومخرجاته الموجهة للإنسان، وتذكر الترجمة العربية إلى جوار الاسم الإنجليزي الثابت للقاعدة أو البوابة عند أول ظهور.

## الأحكام

1. لا يترك شرح أساسي باللغة الإنجليزية وحدها.
2. تبقى المعرّفات الإنجليزية ثابتة للربط مع السجلات والاختبارات.
3. تكون اللغة رسمية وعلمية وسهلة قدر الإمكان.
4. يجوز استعمال **مثال توضيحي خارج النص، وليس دليلًا دلاليًا** لشرح مفهوم معقد.
5. لا يسمح للاختصار بإخفاء البوابات أو UNKNOWN.
