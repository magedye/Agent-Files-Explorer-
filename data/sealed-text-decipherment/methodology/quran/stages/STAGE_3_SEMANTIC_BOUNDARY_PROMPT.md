# Prompt المرحلة الثالثة — الحدود الدلالية

استلم فقط الفرضيات الناجية ومصفوفة الدحض والملفات البنيوية.

أنتج:

- Root Core Candidate بصيغ غير دائرية.
- REQUIRED / PERMITTED / EXCLUDED / UNKNOWN.
- Decisive vs Structurally Sensitive Contexts.
- Nearest Lexemes وSemantic Residue.
- سلاسل Root-to-Local Meaning لمواضع ممثلة.
- Positive Core Robustness وNegative Determination Robustness برتب وصفية.
- Reopen/Falsification Condition.

إذا لم تُفرد النواة أو بقي تناقض حقيقي، أخرج `LOCK_BLOCKED` أو `C0_PREFERRED`.
