# معيار التغطية واستنفاد الأدلة

## 1. سياسات التغطية

### الجذر المحدود — افتراضيًا <=20 موضعًا

- فهرس 100%.
- تحليل عميق 100%.
- لا دعوى اكتمال بلا Evidence Matrix.

### الجذر الواسع — افتراضيًا >20 موضعًا

- فهرس بنيوي 100% إن توفر مصدر قانوني/معتمد.
- عينة عميقة >=10، وتشمل:
  - كل صيغة موثقة رئيسية؛
  - كل تركيب/حرف متكرر عالي الأثر؛
  - المجالات المادية والمجردة؛
  - المواضع الشاذة والمقاومة؛
  - عينة موزعة على سور مختلفة.
- التوسع يستمر إذا ظهر عنقود جديد أو تناقض أو انخفاض في التغطية السياقية.

## 2. استنفاد الأدلة

يجوز إصدار `NO_FURTHER_INTERNAL_DISCRIMINATION_FOUND` عندما:

1. كل المواضع مفهرسة أو نطاق النقص معلن؛
2. كل العناقيد البنيوية المعروفة ممثلة؛
3. أعيد فحص أصعب المواضع والبدائل؛
4. التوسعة الأخيرة لم تضف discriminator جديدًا؛
5. لا يوجد مصدر داخلي مسموح لم يُفحص؛
6. تبقى البدائل متعادلة بصدق.

هذه النتيجة لا تثبت استحالة الحسم مستقبلًا؛ تسجل Reopen Condition.

## 3. C0

`C0` ليست «توقفًا». هي فرضية منافسة: لا نواة إيجابية مميزة مثبتة تحت الأدلة الحالية. تفوز فقط بعد تنفيذ المسار المطلوب، وتنتج حالة محددة لا عبارة عامة.
