# دليل التشغيل العملي المختصر — v4

## 0. ما قبل التشغيل

- ثبّت target، النسخة المنهجية، النسخة المهارية، Profile النص، المصادر المسموحة والمحجوبة.
- صرّح بحدود العمى: عزل وثائقي، مع بقاء خطر المعرفة البارامترية.
- إذا غاب النص القانوني، لا تدّع تحققًا نهائيًا أو corpus كاملًا.

## 1. بناء الفهرس

- اجمع كل المشتقات المرشحة.
- افصل `INDEX COVERAGE` عن `DEEP ANALYSIS COVERAGE`.
- وسم الخلافات: root/lemma/form/parse.

## 2. الملفات المحلية

لكل موضع عميق:

- النص والمرجع.
- الصيغة والتركيب والبدائل.
- المشاركون والحروف.
- Observation / Constraint / Unknown.

لا تضع Root Core في الملف المحلي.

## 3. الفرضيات

- سجل المستبعدات أولًا.
- ولّد فرضيتين إيجابيتين حقيقيتين على الأقل + `C0` عندما تسمح المادة.
- لكل فرضية: REQUIRED، تنبؤ، أصعب موضع، شرط دحض.

## 4. الدحض

- اختبر أصعب موضع.
- اختبر البدائل البنيوية.
- اطرح مساهمات الصيغة والتركيب والمشاركين.
- قارن الجيران داخليًا.
- صنف: SUPPORTS / COMPATIBLE / INDETERMINATE / CONTRADICTS.

## 5. الحدود والتفريد

- REQUIRED / PERMITTED / EXCLUDED / UNKNOWN.
- Nearest Lexemes + Semantic Residue + Substitution.
- إذا بقي التعريف واسعًا، `LOCK_BLOCKED` أو تضييق الدعوى.

## 6. أهلية القفل

يمر الـValidator للحقول الميكانيكية، ثم حكم المراجع للمواد النوعية. القناعة وحدها لا تكفي.

## 7. بعد القفل

- مقارنة مع Priors المشروع فقط.
- أي رأي تاريخي/تفسيري يحتاج مصدرًا موثقًا وملحقًا منفصلًا.
- لا تعديل صامت.

## 8. التدقيق المنهجي

يُجرى بعد تشغيل مكتمل سواء انتهى بقفل أو `LOCK_BLOCKED`. استخرج Failure Modes وقواعد/تنقيحات/Regression.
