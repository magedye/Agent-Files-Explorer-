# Lisan Quranic Semantic Methodology — v3.2.0 Consolidated Upgrade Specification

**Status:** implementation specification  
**Package date:** 2026-08-15  
**Source cycles:** BWA, RJL, AMN, SLM stress tests + owner constitutional decisions.

## 1. Upgrade objective

v3.2.0 must improve falsifiability, source isolation, form/structure discipline, operator analysis, coverage claims, lock governance, and final result traceability without leaking semantic priors into blind discovery.

## 2. Constitutional changes — active immediately

### QURAN-INTERNAL SEMANTIC SOVEREIGNTY
Quran-internal semantic evidence only. Remove/override every older clause permitting inherited semantic authorities for hypothesis generation, corroboration, enrichment, correction, or validation.

### MANDATORY LAYERED SEMANTIC ANALYSIS & PRESENTATION PROTOCOL
Every semantic result must visibly include:
1. Root-Core qualification criteria.
2. Multi-formulation Root Core + diverse explanatory examples.
3. REQUIRED / PERMITTED / EXCLUDED / UNKNOWN and can/cannot entailments.
4. Representative verses.
5. Decisive/governing contexts and their inferential role.
6. Quran-internal lexical-neighbor differentiation.
7. General operator/form/particle/construction analysis with claim-scope labels, followed by target application.
8. Local meaning derivation: `ROOT + FORM + PARTICLE/CONSTRUCTION + ARGUMENTS + CONTEXT`.
9. Coverage/confidence/structural stability/lock status/falsification.
10. Methodology findings and rule/regression candidates.

## 4. Proposed rules retained for regression, not yet authoritative

### R109 — UNATTESTED-BASE FORM CAUTION GATE
A marked/derived form cannot be interpreted via an invented unattested base gloss. Root Core must be recovered from attested family evidence, and form-operator certainty downgraded.

### R110 — PRIVATIVE-CORE POSITIVE-RESIDUE GATE
A pure `absence of X` core must be challenged with contexts where absence of X is independently expressed while the target remains non-redundant. Residue must be layer-attributed before root promotion.

Current status: `PROPOSED / REGRESSION_PENDING`.

## 5. Existing-rule refinements

Integrate refinements to:
- ROOT CORPUS UNITY: unity does not erase form stratification or prove a bridge.
- DERIVATIONAL LAYERING: prefer attested family/least-marked evidence before marked-form operator claims.
- EXPLANATORY SPECIFICITY: require negative prediction and lexical residue.
- SEMANTIC EXCLUSION LEDGER: mandatory `rejection_scope`.
- DECISIVE CONTEXT: structural robustness prerequisite.
- CORE-TO-REALIZATION chain: include particle/construction + argument semantics.
- OPERATOR INVARIANCE: generalization direction from morphology to particles/constructions, with strict separation between **invariance principle** and **empirical operator value**.
- SAME-VERSE LEXICAL COLLISION: proves non-identity, not positive residue by itself.
- REGISTRY GOVERNANCE: `LOCK ≠ OWNER ACCEPTANCE ≠ REGISTRY ADOPTION`.

## 6. Operator-analysis discipline

### Invariance principle
Recurring operators are investigated under a one-invariant-contribution hypothesis.

### Empirical value is separate
Do not promote concrete values such as:
- `أَفْعَلَ = CAUSE/ESTABLISH`
- `ب = ANCHOR`
- `ل = DIRECTION`
until required cross-root/cross-construction evidence exists.

### Mandatory claim-scope labels
- `LOCAL_CONSTRUCTION`
- `ROOT_INTERNAL`
- `CROSS_ROOT_SUPPORTED`
- `CORPUS_WIDE_SUPPORTED`
- `REGRESSION_BACKED`
