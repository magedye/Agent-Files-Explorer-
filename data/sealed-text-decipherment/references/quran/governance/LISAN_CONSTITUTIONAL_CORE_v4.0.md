# النواة الدستورية الموحّدة لمشروع «لسان» — v4.0

**المعرّف:** `LISAN-CONSTITUTIONAL-CORE-4.0`  
**الحالة:** `OWNER-DIRECTED / ACTIVE FOR CONSOLIDATED PACKAGE`  
**الغرض:** توحيد الأهداف والمبادئ غير القابلة للتنازل، وإزالة التعارض بين الوثائق الإجرائية، وتحديد ما يُنفذ الآن وما يُرحّل إلى المنصة البرمجية.

> هذه الوثيقة هي المرجع الدستوري الأعلى داخل الحزمة بعد تعليمات المالك الصريحة الحالية. جميع الوثائق الأخرى تشرحها أو تنفذها، ولا يجوز أن تناقضها.

---

## 1. الهدف الأعلى

بناء منهج قرآني داخلي صارم وقابل للدحض والتكرار لاستخراج **المفهوم الجذري الواحد**، ومساهمات الصيغ والعوامل والتركيبات، والمعاني الموضعية، مع منع المعنى المسبق، وحفظ عدم اليقين، وتحويل كل تجربة إلى تحسين منهجي قابل لإعادة الاستخدام.

**قاعدة القيمة:** **قيمة المنهج أعلى من الجواب المحلي (`METHOD VALUE > LOCAL ANSWER`)**.

# 2. المبادئ غير القابلة للتنازل

## C01 — السيادة الدلالية القرآنية الداخلية (`QURAN-INTERNAL SEMANTIC SOVEREIGNTY`)

المعنى القرآني يُكتشف ويُختبر من القرآن نفسه. لا تعمل التفاسير أو المعاجم أو الحديث أو الشعر أو الترجمات أو المصطلحات اللاحقة أو ذاكرة النموذج بوصفها دليلًا أو مولد فرضية أو مؤيدًا أو مرجحًا داخل المسار الدلالي.

يجوز بعد قفل صالح، وبطلب مالك صريح، إعداد **مراجعة تاريخية/تفسيرية منفصلة** تقيس الآراء بالنتيجة القرآنية المقفلة، ولا تدخل في الثقة أو الاعتماد ولا تعيد كتابة القفل.

## C02 — سلطة النص القانوني (`CANONICAL TEXT AUTHORITY`)

الـProfile القرآني المعتمد هو **رواية حفص عن عاصم، مصحف المدينة**. لا تُستخدم القراءات الأخرى دليلًا دلاليًا في هذا الـProfile. لا يُدّعى تحقق نهائي للاقتباس أو اكتمال corpus دون Artifact قانوني مسجل بإصدار وبصمة وسلالة.

## C03 — منع المعنى المسبق مع الإفصاح عن الافتراضات المنهجية (`ZERO SEMANTIC PRIOR, EXPLICIT METHODOLOGICAL ASSUMPTIONS`)

يبدأ الهدف الدلالي من `UNKNOWN`. المقصود بالصفر هو **صفر المعاني الموروثة المستعملة دليلًا**، وليس غياب المنهج. الافتراضات المنهجية — مثل النواة الواحدة وتغاير المبنى والمعنى — معلنة، ومثبتة الإصدار، ولا تتغير أثناء التشغيل؛ وتراجع بين التشغيلات بقرار مالك وتدقيق منهجي.

العمى المقصود هو **عزل المصادر الوثائقية والجلسية**، لا ادعاء محو المعرفة البارامترية للنموذج.

## C04 — مفهوم جذري واحد لهوية جذرية مؤكدة (`SINGLE ROOT CORE`)

لكل **هوية جذرية مؤكدة** مفهوم محوري واحد ثابت عبر مشتقاتها الصريحة. الصرف والتركيب والسياق يضيفان طبقات ولا يستبدلان النواة.

إذا تعذر إثبات أن شكلين ينتميان إلى هوية جذرية واحدة، تُفتح حالة بنيوية مثل:

- `ROOT_ASSIGNMENT_UNCERTAIN`
- `HOMOGRAPHY_CANDIDATE`
- `LEXEME_PARTITION_CANDIDATE`

ولا يُعلن تعدد نوى داخل جذر مؤكد لمجرد فشل صياغة النواة. هذا مخرج للشك في **هوية الأسرة**، لا استثناء مجاني من مبدأ النواة الواحدة.

## C05 — تغاير المبنى والمعنى وثبات مساهمة العامل (`FORM–MEANING COVARIANCE`)

كل تغير معتبر في المبنى يستلزم البحث عن فرق دلالي معتبر. لكل صيغة أو حرف أو تركيب متكرر مساهمة مرشحة ثابتة تُختبر عبر الجذور والسياقات. لا يثبت وجود البنية أو كثرتها معناها، ولا تُدمج طبقات العامل الصرفي في gloss واحد.

## C06 — corpus أولًا ووحدة corpus الجذر (`CORPUS-FIRST / ROOT CORPUS UNITY`)

لا تُقترح نواة قبل حصر الأسرة ومظاهرها البنيوية. تُجمع المشتقات الصريحة افتراضيًا في corpus واحد، مع وسم الخلاف في إسناد الجذر أو اللمة.

التغطية تُعرض بمقاييس منفصلة:

1. **تغطية الفهرس (`INDEX COVERAGE`)**: عدد المواضع المفهرسة من الإجمالي.
2. **تغطية التحليل العميق (`DEEP ANALYSIS COVERAGE`)**: المواضع التي لها ملفات ملاحظة واختبار كامل.
3. **تغطية تنوع السياقات (`CONTEXT DIVERSITY COVERAGE`)**.
4. **الثبات البنيوي (`STRUCTURAL STABILITY`)**.
5. **متانة النواة الإيجابية** و**متانة الاستبعادات السلبية** بوصفهما رتبًا وصفية لا احتمالات رقمية.

لا تُستخدم نسبة مئوية للثقة الدلالية بلا معايرة مستقلة.

## C07 — الفصل الطبقي والتتبع (`LAYER SEPARATION / ROOT TRACEABILITY`)

المعنى الموضعي يُشتق عبر السلسلة:

```text
ROOT CORE
+ STEM FORM
+ ASPECT / VIEW
+ VOICE
+ MOOD
+ NOMINALIZATION / PARTICIPLE
+ PARTICLE / CONSTRUCTION
+ ARGUMENT SEMANTICS
+ CONTEXT
= LOCAL MEANING
```

يجب بيان مساهمة كل طبقة. إذا تعذر تتبع المعنى الموضعي إلى النواة بلا قفزة، تفشل الدعوى.

## C08 — الملاحظة قبل التأويل، والمجهول نتيجة صحيحة (`OBSERVATION ≠ INTERPRETATION / UNKNOWN IS VALID`)

تصنّف الادعاءات إلى: `OBSERVATION`, `CONSTRAINT`, `HYPOTHESIS`, `INFERENCE`, `RESULT`, `UNKNOWN`. لا تُملأ الفجوات بعبارة مقنعة أو معنى مشهور.

## C09 — الدحض والسياق الحاسم والنفي قبل التحديد (`FALSIFICATION / DECISIVE CONTEXT / NEGATIVE DETERMINATION`)

لا تُقبل فرضية لكثرة المؤيدات، بل لنجاتها من أقوى معارض وأصعب موضع وبدائل بنيوية معقولة. يجوز حسم ما لا يمكن أن يكون نواة قبل حسم النواة الصحيحة، ويُحفظ ذلك في **سجل الاستبعادات الدلالية**.

السياق لا يوصف بالحاسم إذا كانت قوته تعتمد على تحليل بنيوي غير مستقر.

## C10 — الهوية اللفظية المميزة (`LEXICAL DISTINCTIVENESS`)

لا يكفي أن ينسجم التعريف مع corpus؛ يجب أن يفسر لماذا استُخدم الجذر المستهدف بدل أقرب الألفاظ القرآنية. التفريد المناسب لنطاق الدعوى شرط لأهلية القفل، مع السماح بنتيجة `UNRESOLVED` إذا لم يثبت الفرق.

## C11 — الفصل بين القفل والقبول والاعتماد (`LOCK ≠ ACCEPTANCE ≠ ADOPTION`)

- `LOCK_INTERNAL_RESULT`: لقطة داخلية مجمدة.
- `OWNER_ACCEPTANCE`: قرار مالك.
- `REGISTRY_ADOPTION`: تحديث مرجعي versioned.
- `INDEPENDENTLY_REVIEWED`: مراجعة مستقلة موثقة.
- `RELEASE_ACCEPTED`: سلطة الإصدار المحددة بالمشروع.

لا تعاد كتابة النتيجة المقفلة صامتًا بعد كشف Prior؛ أي تغيير Revision مستقل ذو provenance.

## C12 — العربية أولًا والعرض الصادق (`ARABIC-FIRST SCIENTIFIC PRESENTATION`)

العربية الفصحى الرسمية والواضحة هي لغة العرض البشرية الأساسية، ويذكر الاسم العربي إلى جوار المعرّف الإنجليزي عند أول ظهور. لا يسمح الاختصار بإخفاء `UNKNOWN` أو الاستبعادات أو حالة القفل أو محدودية التغطية.

## C13 — الحد الأدنى الفعال من الحوكمة (`MINIMUM EFFECTIVE GOVERNANCE`)

لا تُضاف قاعدة أو Artifact أو بوابة إلا إذا:

1. حمت مبدأ دستوريًا؛ أو
2. منعت نمط فشل ظهر فعليًا؛ أو
3. جعلت ادعاءً جوهريًا قابلًا للتحقق؛ أو
4. خفضت عبء التشغيل من دون خفض الصرامة.

تُفصل صحة المشكلة عن صحة الحل المقترح: `PROBLEM VALIDITY ≠ SOLUTION VALIDITY`.

# 3. افتراضات منهجية معلنة وليست معاني مسبقة

هذه افتراضات تشغيلية يلتزم بها التشغيل المثبت، وتراجع خارج التشغيل:

- النص المحكم ذو انتظام قابل للاختبار.
- الهوية الجذرية المؤكدة تحمل نواة واحدة.
- تغير المبنى ليس مجانيًا دلاليًا.
- السياق يختار وجه التحقق ولا يعيد تعريف الجذر.
- الفروق اللفظية القرآنية ليست ترادفًا تامًا افتراضيًا.

إذا ظهرت مادة مقاومة، لا تُلغى هذه الافتراضات داخل التشغيل تلقائيًا؛ بل تُفتح مراجعة منهجية أو بنيوية، ويجوز أن تكون النتيجة `UNKNOWN`, `ROOT_ASSIGNMENT_UNCERTAIN`, أو `HUMAN_REVIEW_REQUIRED`.

# 4. مبدأ التنفيذ

> **النموذج يقترح؛ الأدلة والبوابات والسلطة الموثقة تحسم.**

في بيئة Skill الحالية، يُخفّف الاعتماد على امتثال النموذج عبر:

- نواة تشغيل مختصرة؛
- حزم قواعد مرحلية؛
- Schemas وValidators للقطع الأثرية الأساسية؛
- فصل حزمة Blind Lab عن حزمة Project Hub؛
- مراجعة خصومية مستقلة عند الادعاءات عالية الأثر.

أما محرك الحالة وقاعدة البيانات وتعدد الوكلاء فهي خارطة طريق برمجية، وليست ادعاءً بأنها منفذة داخل Skill النصية الحالية.

# 5. قاعدة التعارض

عند التعارض تكون الأسبقية:

1. تعليمات المالك الصريحة الحالية.
2. هذه النواة الدستورية.
3. قرارات المالك المسجلة غير المتعارضة معها.
4. السجلات الآلية المعتمدة للحالات والموارد.
5. البروتوكولات التنفيذية والقوالب.
6. المراجع الموسعة والأمثلة.
7. المواد المؤرشفة.

لا تتعايش نصوص متناقضة بصمت؛ كل تعارض يُحسم أو يُوسم `SUPERSEDED` أو `DEFERRED`.
