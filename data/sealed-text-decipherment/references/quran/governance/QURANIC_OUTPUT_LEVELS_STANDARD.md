# معيار مستويات إخراج التحليل القرآني

**الاسم الإنجليزي المرجعي:** `QURANIC OUTPUT LEVELS STANDARD`  
**الحالة:** `ACTIVE`  
**الوزن:** `GOVERNANCE / HIGH`

## الغرض

توفير مخرجات قصيرة عند الحاجة من دون استخدام الاختصار للالتفاف على البوابات المنهجية أو إخفاء عدم اليقين.

## المستوى الأول: التقرير الكامل (`FULL_LAYERED_REPORT`)

يُستخدم إلزاميًا في الحالات الآتية:

- أول تحليل لجذر أو لفظ؛
- تحليل Blind Lab؛
- الانتقال إلى `LOCK_INTERNAL_RESULT`؛
- اقتراح تعريف لسجل التعريفات؛
- مراجعة أو اعتراض قد يغير النواة؛
- تقرير بحثي قابل للمراجعة.

يطبق جميع طبقات `MANDATORY LAYERED SEMANTIC ANALYSIS & PRESENTATION PROTOCOL`، ويُرفق بمصفوفة الأدلة وسجل الاستبعادات عند انطباقهما.

## المستوى الثاني: الملخص المنضبط (`CONTROLLED_CONCISE_SUMMARY`)

يجوز فقط إذا تحقق أحد الشرطين:

1. وجود نتيجة مقفلة أو تعريف مرجعي معتمد يُشتق منه الملخص؛ أو
2. طلب المستخدم ملخصًا مرحليًا واضح الحالة لا يُستخدم للقفل أو الاعتماد.

ويجب أن يتضمن على الأقل:

- حالة النتيجة؛
- Root Core أو المرشح الحالي بالعربية؛
- أهم `REQUIRED / EXCLUDED / UNKNOWN`؛
- أقوى سياق حاسم أو سبب عدم وجوده؛
- الفرق بين Root Core والمعنى الموضعي؛
- حالة التغطية والتفريد والقفل؛
- إحالة إلى التقرير الكامل أو السجل المصدر.

لا يجوز أن يحذف الملخص معارضًا مركزيًا أو `UNKNOWN` جوهريًا.

## المستوى الثالث: حالة النظام (`STATUS_ONLY`)

مخرج إداري قصير مثل:

- `LOCK_BLOCKED`؛
- `BLIND_ISOLATION_NOT_VERIFIED`؛
- `CORPUS_INCOMPLETE`؛
- `HUMAN_REVIEW_REQUIRED`.

يجب أن يذكر سبب الحالة والخطوة اللازمة، ولا يقدم معنى دلاليًا جديدًا.

## قاعدة عدم الالتفاف

لا يغير مستوى الإخراج متطلبات الدليل. الاختصار يختصر **العرض** لا **التحليل**.

نمط الفشل الممنوع:

`SHORT ANSWER REQUEST → OMIT GATES/UNKNOWN → UNQUALIFIED SEMANTIC CLAIM`
