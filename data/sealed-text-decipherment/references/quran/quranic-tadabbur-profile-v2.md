# الملف التنفيذي للتدبر اللساني القرآني — الإصدار الثاني

## الغرض والسلطة

هذا الملف يضيف مساراً قرآنياً تنفيذياً إلى المهارة العامة، ولا يغيّر قواعد فك النصوص المجهولة أو أقفالها. عند التعارض تكون الأولوية للدستور القرآني المرفق، ثم قواعد المهارة العامة، ثم هذا الملف، ثم المواد السابقة بوصفها priors.

## الطلبات التي يفعّلها

- تحليل لفظ أو جذر قرآني.
- مقارنة لفظين أو عائلتين اشتقاقيتين.
- تقويم فهم شائع أو فرضية دلالية.
- تدبر آية من جهة اللسان والبنية والسياق.
- تحليل موضوع مركب بتفكيكه إلى ألفاظه وعلاقاته.

لا يصدر فتوى أو حكماً عقدياً نهائياً، ولا يجعل استنتاجاً سابقاً أو معجماً أو تفسيراً نواةً مفروضة.

## المسار التنفيذي

1. **حدد السؤال والنطاق.** عيّن اللفظ أو الجذر أو المقارنة، ونوع الرسم والقراءة ومجال الجمع.
2. **ثبت النص والفهرس.** لا تدع جمعاً كاملاً بلا corpus قانوني وفهرس قابل لإعادة الإنتاج.
3. **استخرج البنية.** استخدم الصرف والنحو والجذر واللمة والحروف بوصفها مرشحات بنيوية، مع حفظ البدائل والسلالة.
4. **ابن ملفاً محلياً لكل موضع.** سجّل الشكل والصيغة والمتعلقات والحروف والبنية والمصاحبات والسياق والبدائل والبواقي، دون النواة المراد إثباتها.
5. **ولد C0 وفرضيات منافسة.** قد تكون C0: لا نواة واحدة، أو تعدد معان/ألفاظ، أو مادة غير كافية.
6. **اقترح النواة.** طبّق:

   ```text
   الدلالة الموضعية = النواة المرشحة + مساهمة الصيغة + مساهمة التركيب + تعيين السياق + البواقي
   ```

7. **اختبر الأسرة الاشتقاقية.** لا يكفي نجاح النواة في صيغة أو مجال واحد.
8. **ابحث عن السياق الحاسم.** استرجع الموضع الذي يثبت الفرضية أو يضيّقها أو ينقضها قبل الترجيح.
9. **قارن النظائر.** اختبر الفروق عبر النواة والمتعلّق والحرف والمجال والأثر واختبار الاستبدال.
10. **قوّم الفهم الشائع.** لا يبدأ الجدل قبل تأسيس الداخل.
11. **اعرض الاعتراض الأقوى.** لا تدافع تلقائياً؛ ضيّق أو ارفض عند المعارض.
12. **اختبر الحساسية والـholdout.** جمّد التنبؤ وشرط الدحض قبل الكشف.
13. **اقفل الداخل.** أنشئ `LOCK_INTERNAL_SEMANTICS`.
14. **افتح الخارج والـpriors.** قارن دون إعادة كتابة اللقطة صامتاً.
15. **أخرج بطاقة بيان أو تقرير امتناع.** اذكر السقف والunknowns والبواقي.

## طبقات الأدلة المعتمدة

- **أ:** نص قرآني مباشر متحقق في الموضع.
- **ب:** استنتاج داخلي من الجمع أو المقارنة القرآنية أو الصرف أو النحو أو السياق.
- **ج:** مقارنة خارجية بعد القفل.
- **د:** احتمال أو عدم حسم أو نقص مادة.

المقارنة بين لفظين داخل القرآن طبقة **ب**، حتى لو سمتها مصادر قديمة «ج». لا يختلط الخارج بالاحتمال.

## تنوع السياقات

ثلاثة سياقات متباينة قيمة افتراضية نافعة لا قانوناً عددياً مطلقاً. عند قلة المادة:

- اجمع كل الموجود.
- صرّح بندرته.
- اخفض سقف التعميم.
- لا تخلق سياقات مصطنعة لإكمال العدد.

## العقل والعدل والاتساق

تستعمل بوصفها اختبارات اتساق تكشف الفهم الذي يفضي إلى تناقض أو عبث أو ظلم أو إلغاء مسؤولية دون دليل. لا تستعمل لفرض نتيجة سابقة أو إلغاء نص محكم.

## النتيجة المشروعة

قد تكون: قوي، راجح، محتمل، ضعيف، مرفوض، غير كافٍ للجزم، متعدد النوى، أو مراجعة بشرية مطلوبة. الامتناع نجاح منهجي.
