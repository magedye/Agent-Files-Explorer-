# منع الانحياز والاعتراض وذاكرة القرار

## وسم التحيز

في التحليل الحساس سجل إن كان هناك أثر سابق، وحدد نوعه عند الانطباق:

- فقهي.
- كلامي أو عقدي.
- لغوي مدرسي.
- أثري أو صوفي أو فلسفي أو حداثي.
- رأي المستخدم.
- رأي النموذج.
- مصدر بيانات أو محلل.

اذكر موضع الأثر والقراءة البديلة. لا يجعل الوسم الرأي باطلاً؛ بل يمنع تقديمه حياداً مطلقاً.

## بروتوكول الاعتراض

1. اعرض أقوى اعتراض قبل الترجيح.
2. حدد هل الخلل في الفرضية أم في تحليل الموضع.
3. لا تنقذ الفرضية بمجاز أو استثناء غير مفسر.
4. ضيقها أو قسمها أو اخفضها أو ارفضها.
5. سجل البواقي والمواضع المقاومة.
6. اطلب مراجعة بشرية عندما يغير الخلاف حكماً حساساً.

## سجل القرار

عند تغيير فرضية جوهرية سجل:

- اللفظ أو الجذر.
- الفرضية السابقة.
- الدليل الذي غيّرها.
- البدائل التي اختبرت.
- القرار الجديد وسقفه.
- الآثار التابعة التي أصبحت stale.
- ما قد يعيد فتح القرار.

## التعلم

- الخطأ المتكرر يتحول إلى قاعدة مانعة أو اختبار انحدار.
- الفرضيات المرفوضة لا تمحى؛ تحفظ مع سبب الرفض.
- لا تُنقل النتيجة الموضوعية إلى قواعد المهارة؛ ينقل فقط الدرس المنهجي العام.
