# قائمة تحقق قبل الإخراج

## corpus

- [ ] الأصل محفوظ وغير مستبدل.
- [ ] العناوين والبصمات موجودة.
- [ ] الضرر والقراءات غير المؤكدة معلنة.
- [ ] لا تصحيح صامت.

## البنية

- [ ] الخط واللغة والمعنى مفصولة.
- [ ] البدائل المعقولة محفوظة.
- [ ] التقطيع اختبر لا افترض.
- [ ] القيم الصوتية لها anchors منتظمة.
- [ ] الصرف والنحو لا يحملان gloss مسبقاً.

## الدلالة

- [ ] الملف المحلي مستقل عن النتيجة.
- [ ] توجد C0 وفرضية منافسة.
- [ ] core منفصل عن morphology/construction/context/residual.
- [ ] أقوى معارض مذكور.
- [ ] شرط الدحض واضح.
- [ ] التنبؤات جُمّدت وسُجلت قبل كشف الـHoldout، أو لم يُستخدم Holdout.

## العزل

- [ ] الأقفال موثقة.
- [ ] لا تسرب من priors/external/holdout.
- [ ] lineage والاستقلال موثقان.
- [ ] لا تصويت بالأغلبية.

## الإخراج

- [ ] كل claim موسوم أ/ب/ج/د.
- [ ] مستوى كل محور مسمى بدقة.
- [ ] لا ادعاء full decipherment بلا دليل.
- [ ] unknowns والبواقي ظاهرة.
- [ ] تقرير الامتناع استُخدم عند الحاجة.

## Quran v3 critical checks

- [ ] `ZERO-PRIOR-MEANING` and prior contamination disclosure applied.
- [ ] One invariant Root Concept only for a confirmed root.
- [ ] Every material form change has an investigated semantic contribution.
- [ ] Every explicit derivative is in the root corpus unless root assignment is explicitly uncertain.
- [ ] Local meanings trace back to Root Core through form/syntax/context.
- [ ] No semantic mutation was used to save a hypothesis.
- [ ] Nearest Quranic lexemes were differentiated before high confidence.
- [ ] Tafsir was not used.
- [ ] Canonical Quran profile is Hafs `an Asim / Madinah Mushaf only.

## Quran v3.2 release checks

- [ ] `QURAN-INTERNAL SEMANTIC SOVEREIGNTY` applied; no inherited semantic source used at any stage.
- [ ] `MANDATORY LAYERED SEMANTIC ANALYSIS & PRESENTATION PROTOCOL` complete.
- [ ] Blind Source Manifest pinned; source isolation verifiable.
- [ ] Methodology/Skill versions frozen during the blind run.
- [ ] Exact form identity verified before morphology claims.
- [ ] Any numerical Coverage claim has an occurrence Evidence Matrix.
- [ ] A standalone Semantic Exclusion Ledger exists for full semantic analysis.
- [ ] Multiple genuine positive hypotheses + C0 considered.
- [ ] Structural ambiguity register precedes decisive-context status.
- [ ] Constructional/argument/operator contributions subtracted.
- [ ] Abstract core operationalized and predictive/falsifiable.
- [ ] Distant derivational branches have bridge evidence or remain UNKNOWN.
- [ ] Lock Eligibility Report exists; blocked conditions yield `LOCK_BLOCKED`.
- [ ] Lock, owner acceptance, and registry adoption are separate.
- [ ] R109/R110/R111 applied when triggered.
- [ ] Lexical distinctiveness is sufficient for the intended lock scope.
- [ ] Canonical quote verification uses a pinned text artifact, not QAC/model memory.
- [ ] Arabic-first presentation standard is satisfied.
- [ ] Controlled concise output, if used, did not bypass full analytical gates.
- [ ] Any post-lock opinion/tafsir appendix remained outside semantic validation.

## Quran v3.3 morphological-operator checks

- [ ] استُخدم مرجع العوامل الصرفية v0.2 بوصفه مرجعًا بنيويًا ودفتر فرضيات، لا سلطة دلالية.
- [ ] لكل Operator Claim: `structural_status`, `semantic_status`, و`claim_scope`.
- [ ] لم تُستخدم كثرة الورود أو وسم QAC لإثبات معنى العامل (R112).
- [ ] فُكك المكدس إلى Stem Form / Aspect-View / Voice / Mood / Nominalization-Participle / Construction، ولم يُدمج في gloss واحد (R113).
- [ ] الحاوية غير الموسومة لم تُسمَّ Form I من دون تحقق هوية الصيغة (R98).
- [ ] إذا كان هدف التحليل اكتشاف قيمة العامل، حُجبت الفرضيات الدلالية الجاهزة من المرجع.
