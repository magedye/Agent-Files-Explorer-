# أنماط الأخطاء الشائعة

| الخطأ | المثال | التصحيح |
|---|---|---|
| القفز من التكرار إلى المعنى | العلامة الأكثر تكراراً = «الإله» | التكرار يحدد وظيفة محتملة لا gloss |
| دمج allographs بلا اختبار | شكلان متشابهان = علامة واحدة | اختبر التوزيع التكميلي وأثر الدمج |
| فرض اتجاه القراءة | اختيار اليمين لأن النص مقدس | اختبر layout والمواضع والاتساق |
| التقطيع حسب لغة معروفة | تقسيم السلسلة لتشبه كلمات عربية | قارن segmentations تنبؤياً |
| cognate hunting | جمع خمس كلمات تشبه لغة مرغوبة | اطلب مراسلات منتظمة وnegative controls |
| تصويت المحللات | 3 نماذج قالت اللغة X | افحص lineage والدليل المشترك |
| circular semantics | بناء الملف المحلي بترجمة H1 | أعد بناء profile بلا gloss |
| تفسير كل residual | إنقاذ الفرضية بمجازات واستثناءات | سجل البواقي وخفض/ارفض |
| رؤية holdout مبكراً | تعديل القاعدة بعد كشف الشاهد | جمّد predictions وسجل الكشف |
| الخلط بين القراءة والتفسير | phonetic value = doctrine | افصل claim axes |
| اعتبار السياق الأثري ترجمة | وجد في قبر إذن الكلمة «موت» | السياق يقيد المجال فقط |
| full decipherment inflation | نجاح 20 اسماً = فك اللغة | استخدم حالة جزئية دقيقة |
| إخفاء عدم الحسم | ترجمة ناعمة مع gaps كثيرة | تقرير امتناع أو ترجمة هيكلية |
