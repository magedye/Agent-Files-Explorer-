# ملحق مراجعة الآراء والتفاسير بعد القفل

**الاسم الإنجليزي المرجعي:** `POST-LOCK INTERPRETIVE REVIEW`  
**شرط الاستخدام:** طلب صريح + `LOCK_INTERNAL_RESULT` صالح.

## 0. بيانات العزل

```yaml
review:
  root_or_lexeme: ""
  lock_record: ""
  locked_result_reference: ""
  requested_by: ""
  purpose: "HISTORICAL | INTERPRETIVE | CRITICAL_COMPARISON"
  affects_semantic_confidence: false
  affects_registry_adoption: false
```

## 1. ملخص النتيجة الداخلية المقفلة

يُنقل كما هو من دون تعديل:

- Root Core:
- REQUIRED:
- EXCLUDED:
- UNKNOWN:
- Decisive Contexts:

## 2. الآراء أو التفاسير

| المصدر | الرأي/الدعوى | أوجه الاتفاق مع النتيجة المقفلة | الزيادة غير المثبتة داخليًا | مواضع التعارض | حالة التقويم | ملاحظات |
|---|---|---|---|---|---|---|

حالات التقويم:

- `SUPPORTED_BY_LOCKED_INTERNAL_RESULT`
- `PARTIALLY_SUPPORTED`
- `UNSUPPORTED_BY_CURRENT_INTERNAL_EVIDENCE`
- `CONTRADICTED_BY_LOCKED_INTERNAL_RESULT`
- `NOT_TESTABLE_WITH_CURRENT_SCOPE`

## 3. النتيجة النقدية

- ما الذي يفسره الرأي بصورة منسجمة؟
- ما الذي يخلط فيه Root Core بالصيغة أو السياق؟
- ما الذي لا يثبته corpus؟
- هل كشف الرأي سؤالًا جديدًا يستحق اختبارًا قرآنيًا مستقلًا؟

## 4. قاعدة عدم العكس

الاتجاه المشروع هو:

`LOCKED INTERNAL RESULT → EVALUATES EXTERNAL OPINION`

وليس:

`EXTERNAL OPINION → VALIDATES ROOT CORE`
