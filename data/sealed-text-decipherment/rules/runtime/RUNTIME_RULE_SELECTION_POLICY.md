# سياسة اختيار القواعد أثناء التشغيل

1. اقرأ Runtime Kernel دائمًا.
2. حدّد المرحلة الحالية.
3. حمّل Stage Pack المقابل.
4. استدع قاعدة مفردة إضافية فقط إذا ظهر Trigger موثق.
5. لا تستخدم Vector/RAG غير موثق لتحكيم القواعد؛ في Skill الحالية الاستدعاء deterministic من Stage Pack.
6. إذا تعارضت قاعدة تفصيلية مع الدستور، يتوقف التنفيذ ويُفتح Audit Incident؛ لا يُحل التعارض داخل التحليل الدلالي.
