# قواعد العوامل الصرفية المعتمدة في v3.3.0

## R112 — الإثبات البنيوي لا يساوي إثبات دلالة العامل (`STRUCTURAL ATTESTATION ≠ OPERATOR SEMANTIC VALIDATION`)

- **الوزن:** دستوري/حاجب.
- **الوظيفة:** فصل عدد الورود ووسم المورد البنيوي عن قيمة العامل الدلالية.
- **نمط الفشل:** `STRUCTURAL COUNT → SEMANTIC CERTAINTY`.
- **الأصل:** مراجعة مرجع العوامل الصرفية v0.1.
- **اختبار الانحدار:** لا يثبت عدد Form IV معنى التعدية أو الإحداث.

## R113 — عدم دمج طبقات العوامل الصرفية (`MORPHOLOGICAL OPERATOR STACK NON-COLLAPSE`)

- **الوزن:** دستوري/حاجب.
- **الوظيفة:** تفكيك Root Core وStem Form والمنظور والصوت والمزاج والاشتقاق الاسمي والتركيب.
- **نمط الفشل:** `MULTIPLE OPERATORS → SINGLE UNTRACEABLE GLOSS`.
- **الأصل:** معمارية المرجع الصرفي v0.1 وصقلها في v0.2.
- **اختبار الانحدار:** يجب تحليل `أُنزِلَ` بوصفه Root + Form IV + PERF + PASSIVE، لا بوصفه معنى صيغة واحدًا.
