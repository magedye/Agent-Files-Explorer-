# Conversation Discovery Ledger

This file records important methodological discoveries that appeared in discussion, including those not promoted to formal Rules.

## BWA cycle
- FORM-IDENTITY verification failure discovered from `تبوء` vs `تبوّءا`.
- Root-level exclusion scope must not automatically prohibit local realization.
- Structural ambiguity can invalidate a supposedly decisive context.
- Argument frame cannot substitute for lexical identity.
- Abstract cores need operational/predictive content.
- Same-verse collision proves non-identity, not positive residue by itself.

## RJL cycle
- Cross-derivation bridge evidence needed when branches are materially distant.
- Lexeme-level success can exceed Root-Core closure; do not force root closure to report a valid lexeme-level result.
- Morphological tagging is structural evidence, not automatic lexical identity.
- Negative predictions improve explanatory specificity.

## AMN cycle
- Base/root/form/particle/context decomposition must precede a composite gloss.
- Objective external reality must not be equated with a state if the text can attribute the state despite contrary reality.
- Particle hypotheses must not be treated as Quran-wide laws from one verb.
- Same-particle opposition is useful for subtracting predicate polarity.
- Name/agent compatibility can falsify overly human-specific form definitions.
- `آمن بـ / آمن لـ / آمن + object` require distinct role analysis.

## SLM cycle
- Unattested base forms cannot be supplied with invented glosses.
- A purely negative Root Core may hide a positive residue.
- Residue from a marked form must be layer-attributed before root promotion.
- Nominal branches sharing a root (`سَلَم / سِلْم / سَلام / سُلَّم`) must remain in one root corpus but be stratified by form.
- Form II, Form IV, Form X must not be gloss-collapsed.
- SLM↔AMN non-identity is partly established, but positive lexical residue remains lock-blocking.

## Owner-level methodology decisions
- Quran-internal semantic sovereignty.
- Mandatory layered semantic analysis and presentation.
- Project files/registries are authoritative; chat memory is not.
