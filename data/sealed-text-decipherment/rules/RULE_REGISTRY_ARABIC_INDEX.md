# الفهرس العربي لسجل القواعد والبوابات

**الاسم الإنجليزي المرجعي:** `RULE REGISTRY ARABIC INDEX`  
**الحالة:** `ACTIVE / HUMAN-READABLE VIEW`

هذا الفهرس هو الواجهة العربية لسجل القواعد. يبقى النص السلطوي التفصيلي في `rules/06-quranic-semantic-constitution-v3.md`، ويبقى الاسم الإنجليزي معرّفًا ثابتًا للربط مع الاختبارات والمخططات.

| المعرّف | الاسم العربي | الاسم الإنجليزي الثابت | الوظيفة العربية المختصرة |
|---|---|---|---|
| R01 | منع المعنى المسبق | `ZERO-PRIOR-MEANING / PRECONCEPTION PROHIBITION` | يمنع بدء التحليل بمعنى محفوظ أو شائع ويُلزم البدء من UNKNOWN. |
| R02 | الإفصاح عن تلوث المعرفة المسبقة | `PRIOR-CONTAMINATION DISCLOSURE` | يسجل ظهور معنى مألوف بوصفه Prior ملوثًا لا دليلًا. |
| R03 | بوابة corpus أولًا | `CORPUS-FIRST GATE` | تمنع اقتراح النواة قبل بناء corpus مناسب. |
| R04 | قاعدة التغطية الكاملة للجذور قليلة الورود | `LOW-FREQUENCY FULL COVERAGE RULE` | تلزم فحص جميع المواضع عندما يكون corpus صغيرًا. |
| R05 | قاعدة تغطية الجذور كثيرة الورود | `HIGH-FREQUENCY ROOT COVERAGE RULE` | تحدد الحد الأدنى للعينة المتنوعة والتوسع اللاحق. |
| R06 | قاعدة العينة الخصومية | `ADVERSARIAL SAMPLING RULE` | تختار المواضع التي تحاول إسقاط الفرضية لا تأكيدها. |
| R07 | وحدة corpus الجذر | `ROOT CORPUS UNITY RULE` | تجمع المشتقات الصريحة في أسرة واحدة ما لم يثبت فصل صرفي. |

| R10 | تحليل كل موضع مستقلًا | `INDEPENDENT OCCURRENCE ANALYSIS` | يمنع تفسير موضع سابق من فرض نتيجة على المواضع اللاحقة. |
| R11 | الملاحظة لا تساوي التفسير | `OBSERVATION ≠ INTERPRETATION` | يفصل الواقعة النصية عن القيد والفرضية والاستنتاج. |
| R12 | المجهول نتيجة صحيحة | `UNKNOWN IS VALID` | يحفظ UNKNOWN بدل سد الفجوات بالتخمين. |
| R13 | المفهوم قبل المرادف | `CONCEPT BEFORE GLOSS` | يبني البنية المفهومية قبل اختيار gloss مختصر. |
| R14 | الحزمة الدلالية قبل المرادف الواحد | `SEMANTIC BUNDLE BEFORE SINGLE GLOSS` | يسمح بتعريف متعدد الخصائص قبل ضغطه في لفظ واحد. |
| R15 | النواة الدنيا الكافية | `MINIMAL SUFFICIENT INVARIANT` | يبحث عن أضيق مفهوم يفسر الأسرة من دون زيادة. |

| R18 | فصل الجذر والصيغة والنحو والسياق | `ROOT / FORM / SYNTAX / CONTEXT SEPARATION` | يمنع خلط طبقات الإسهام الدلالي. |
| R19 | الصرف يعدل الحدث لا النواة | `MORPHOLOGY MODIFIES THE EVENT, NOT THE ROOT CORE` | يحفظ الجذر ويعزو الفروق إلى الصيغة. |
| R20 | طبقات الاشتقاق | `DERIVATIONAL LAYERING` | ينظم الانتقال من النواة إلى المعنى الملفوظ عبر الطبقات. |
| R21 | السياق يختار ولا يعيد التعريف | `CONTEXT SELECTS, IT DOES NOT REDEFINE` | يجعل السياق محددًا للوجه لا منشئًا لنواة جديدة. |
| R22 | تركيب معنى الملفوظ | `UTTERANCE MEANING COMPOSITION` | يقرر أن المعنى الموضعي حصيلة الجذر والصيغة والتركيب والسياق. |
| R23 | بوابة تتبع النواة | `ROOT-TRACEABILITY GATE` | تشترط رد المعنى الموضعي إلى النواة عبر سلسلة ظاهرة. |

| R26 | اختبار ثبات النواة عبر الاشتقاقات | `CROSS-DERIVATION INVARIANCE TEST` | يتحقق من بقاء المفهوم في الأسماء والأفعال والصيغ المختلفة. |
| R27 | التفريد الدلالي وعدم الترادف التام | `LEXICAL DISTINCTIVENESS / NON-SYNONYMY PRINCIPLE` | يشترط هوية تميز الجذر عن الألفاظ القريبة. |
| R28 | الأصل عدم الترادف التام | `NO PERFECT SYNONYMY AS DEFAULT` | لا يفترض تطابق لفظين قرآنيين مختلفين بلا دليل استثنائي. |
| R29 | التفريق عن أقرب لفظ | `NEAREST-LEXEME DIFFERENTIATION` | يقارن الجذر بأقرب المنافسين المكتشفين داخليًا. |

| R32 | بوابة التصادم اللفظي | `LEXICAL COLLISION GATE` | تمنع مساواة لفظين يؤديان وظيفتين مستقلتين في السياق. |
| R33 | حياد الإطار المرجعي | `REFERENCE-FRAME NEUTRALITY` | يمنع افتراض محور أعلى/أسفل أو قرب/بعد قبل اكتشافه. |
| R34 | اختبار الدلالة العلائقية | `RELATIONAL-SEMANTICS CHECK` | يفحص ما إذا كان الجذر يصف علاقة بين أطراف. |
| R35 | ثبات النواة بين المادي والعلاقاتي | `PHYSICAL–RELATIONAL INVARIANT` | يحافظ على بنية واحدة عبر المجالات المختلفة. |
| R36 | نمذجة الانتقال بين الحالات | `STATE-TRANSITION MODELING` | يمثل الحالة قبل الفعل وبعده لتقييد الفرضيات. |
| R37 | البحث عن محور التقابل | `CONTRAST-AXIS SEARCH` | يستخرج المحور المشترك من البنى المتقابلة. |
| R38 | عدم التكرار البنيوي | `STRUCTURAL NON-REDUNDANCY` | يفترض قيمة تمييزية لذكر عنصرين في بنية اختيار أو عطف. |
| R39 | بوابة الجار التقابلي | `CONTRASTIVE-NEIGHBOR GATE` | تلزم تحليل الجار مستقلًا إذا كان الفرق معه حاسمًا. |
| R40 | المجاورة لا تعني الترادف | `ADJACENCY ≠ SYNONYMY` | تمنع تعريف الجذر بلفظ قريب في السياق لمجرد جواره. |
