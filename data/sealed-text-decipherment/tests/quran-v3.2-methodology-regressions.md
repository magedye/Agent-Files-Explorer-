# AMN/SLM Methodology Regression Package

These are tests, not independent Rules/Gates.

## FORM IDENTITY REGRESSION
Target: R98.  
Must fail: treating `أَمِنَ` and `آمَنَ`, or `أَسْلَمَ` and `سَلَّمَ/استسلم`, as the same form contribution.

## SAME-ROOT FORM GLOSS COLLAPSE TEST
Targets: R09/R70.  
Must fail: `أَسْلَمَ = استسلم` or `أَسْلَمَ = سلَّم` as complete identities merely because they share SLM.

## CLAIMED-STATE REGRESSION
Target: R11.  
Case: a quoted claim such as `آمنا` is not evidence that the claimed state is realized when the text explicitly denies it.

## SAME-PARTICLE OPPOSITION TEST
Targets: R104 and operator-invariance refinement.  
Case family: the same particle with contrasting predicates must not inherit predicate polarity. The test may generate an operator hypothesis but cannot promote a Quran-wide particle value without the required scope.

## SAME-CLAUSE ARGUMENT TRIANGULATION TEST
Target: R104.  
Use only after syntactic attachment is established. A clause containing a direct object and multiple particle arguments can help isolate relative argument roles.

## FALSE-SECURITY REGRESSION TEST
Target: existing falsification/semantic-boundary controls; candidate evidence for EXTERNAL-REALITY NON-EQUIVALENCE if later promoted.  
A proposed AMN core must not require objective external safety when the textual state can be attributed despite later/possible harm.

## SELF-REENTRANT IMPERATIVE TEST
Targets: structural non-redundancy / hypothesis lifecycle.  
An analysis must not define a verb as a one-time irreversible transition if the text can address prior bearers of the description with the same imperative without contradiction.

## PRIVATIVE-CORE RESIDUE REGRESSION
Target: R110.  
A pure `absence of X` core must be challenged with a context where absence of X is independently expressed and the target remains non-redundant. Residue from a marked form must be layer-attributed before being assigned to the root.

## UNATTESTED-BASE REGRESSION
Target: R109.  
When a marked form is attested and a supposed base verb is not, the analysis must not invent the base gloss and use it as operator evidence.

## DECISIVE PARSE ROBUSTNESS REGRESSION
Targets: R101/R102.  
A context loses `DECISIVE` status if a reasonable material parse turns the claimed contradiction into indeterminacy.
