# اختبار انحدار بروتوكول العرض الطبقي الإلزامي

يفشل التقرير إذا حذف بصمت طبقة لازمة:

1. مواصفات صلاحية Root Core.
2. Root Core بعدة صياغات عربية متكافئة وبنية مفهومية وأمثلة.
3. REQUIRED / PERMITTED / EXCLUDED / UNKNOWN.
4. الآيات الممثلة.
5. السياقات الحاسمة ووظيفتها الاستدلالية.
6. Evidence Matrix وSemantic Exclusion Ledger أو إحالة صريحة إليهما.
7. التفريد القرآني الداخلي عن الجيران.
8. تحليل الصيغ والحروف والتراكيب مع Scope، ثم التطبيق.
9. المعاني الموضعية المشتقة تركيبياً.
10. Corpus Coverage / Context Diversity / Confidence / Structural Stability / Lock.
11. شروط الدحض وإعادة الفتح.
12. المكتسبات المنهجية ومرشحات القواعد والانحدار.
13. الملحق التفسيري/التاريخي فقط إذا طلب بعد القفل، مع وسمه غير حاكم.

## اللغة

يفشل التقرير إذا ترك شرحًا أساسيًا بالإنجليزية وحدها. عند أول ظهور يكتب:

> **الاسم العربي (`CANONICAL ENGLISH ID`)**

## النقص

المتوقع عند غياب الدليل:

`UNKNOWN / INCOMPLETE / NOT YET ANALYZED`

لا يجوز حذف الطبقة أو تعويضها بعبارة بلاغية.
