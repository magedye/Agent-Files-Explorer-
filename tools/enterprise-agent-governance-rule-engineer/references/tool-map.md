# أدوات مساندة بحسب طبقة التدخل — Tool selection, not endorsement

الأدوات التالية أمثلة معروفة للفئات، وليست تكاملات مثبتة في هذه المهارة. تتحقق من إمكانيات الإصدار الحالي عند الاستخدام. **هذه المهارة لا تتطلب تثبيت أي منها**، ولا تستدعي تلقائيًا أي خدمة خارجية.

| الفئة | أمثلة | مكان التدخل | الاستخدام والحد |
|---|---|---|---|
| Instruction Optimization | DSPy | قبل التوليد | تحسين أمثلة/تعليمات وفق معيار تقييم؛ ليس تفويضًا |
| Prompt Management | Langfuse Prompts؛ AGENTS.md | الإدارة ونسخ التعليمات | مصدر وإصدار؛ لا يعني حالة APPPROVED فعلية |
| Structured Outputs | Outlines؛ Instructor؛ BAML؛ Jsonformer | أثناء/بعد التوليد | ضبط البنية وإعادة المحاولة؛ صحة الشكل ≠ سلطة |
| Behavioral Guardrails | NeMo Guardrails؛ Guardrails AI؛ Llama Guard | مدخلات/مخرجات/تدفق | أنظمة متباينة؛ Llama Guard تصنيف سلامة محتوى وليس حلًا كاملًا لحقن التعليمات |
| Policy-as-Code | OPA/Rego؛ Cedar؛ Casbin | قبل تنفيذ الأداة | سياسة قرار تحتاج PEP والهوية وإثبات عدم التجاوز |
| Integrated Governance | Microsoft Agent Governance Toolkit؛ Amazon Bedrock AgentCore؛ Qodo | عدة طبقات | تغطية مختلطة؛ Qodo أقرب لتطوير البرمجيات وليس منصة عامة لفرض صلاحيات أي وكيل |
| Evaluation & Red Teaming | Promptfoo؛ DeepEval؛ Giskard؛ Ragas؛ Langfuse Evals | خارج/داخل التشغيل | التقييم يكشف حالات؛ ليس بوابة أذونات مستقلة |

نقاط تمييز:
- `Instructor`: التحقق من مخرجات النموذج وإعادة المحاولة وفق schema؛ ليس بالضرورة توليدًا مقيّدًا عند كل token.
- `Outlines`: يمكنه تقييد شكل التوليد حين يدعم المحرك ذلك؛ الضمان متعلق بالنحو/البنية لا صحة المعنى.
- `OPA` و`Cedar`: تعبير وتقييم سياسات وصول؛ لا يمسكان الأداة تلقائيًا إذا لم يوضع PEP عند نقطة التنفيذ.
- **المنصة المتكاملة ليست «المرحلة التاسعة» بعد عملية التنفيذ**؛ تتيح طبقات متداخلة عبر دورة العمل.

لا تستنتج من اسم منتج ضمانًا أنه يدعم تفويضًا أصيلًا على كل مورد أو ميزة. ارجع إلى توثيق الإصدار وإلى الاختبارات الميدانية المستقلة.
