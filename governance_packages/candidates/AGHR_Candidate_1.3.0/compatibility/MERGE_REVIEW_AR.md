# مراجعة الدمج — AGHR 1.1.0

## الأصل والتفويض
الأصل هو الأرشيف الكامل Agent_Governance_Harness_Reference_1.0.0(1).zip المرفق من المالك، وليس AGHR Minimal. جرد الأصل يضم 135 ملفًا، وجرد الإضافات 78 ملفًا. حُفظت هويات المدخلات وبصماتها في [سجل المدخلات](AGHR_1_0_INPUTS.json). التفويض هو مراجعة الأرشيف ودمج الإضافات المتفق عليها في نسخة كاملة؛ لا يشمل تبنيها في مشروع قائم أو تغيير إعدادات مضيف أو دمج Git أو دفعه أو النشر الإنتاجي.

## ما حُفظ
حُفظت العقود الأربعة: الحوكمة والتشغيل والإنفاذ والأدلة. بقي `registry/RULES.json` سجل القواعد الوحيد، وبقيت متطلبات المنتج وقرارات المالك منفصلة عن الأدوات. حُفظت معرفات القواعد الأربعين السابقة. لم تُعدّل بايتات `design/frozen/` ولا ملفات `compatibility/V4_*` التاريخية. هذه السجلات توثّق مراجعة 1.0؛ لا يعني حفظها أن المراجعة التاريخية أعيد تنفيذها باستقلال في هذه الجلسة.

## قرارات المصالحة
نُقحت AGHR-010 و011 و023 و038 داخل مواضعها لتغطية الاستمرار والاستيضاح وتأكيد الأثر والمهارات الخارجية. أضيفت AGHR-041 إلى047 لما يحتاج قاعدة مستقلة: الاستيضاح الذكي، البدائل، دورة الحياة، إغلاق الفروع، التواصل، قياس الانحراف، وانطباق المعايير. رُبطت بنود الإضافات الاثنا عشر بالسجل ولم يُنسخ سجل EXT كسلطة ثانية. راجع [مصفوفة البنود](ADDITIONS_CONTROL_MAPPING.json).

لم تُرقَّ التوصيات الأكاديمية أو بطاقات المعايير أو المهارات الاختيارية إلى قواعد مطبقة على كل مشروع. تؤخذ الوثائق الرسمية المتوافقة مع إصدار النموذج والمضيف مرجعًا تقنيًا؛ لا يمنح أي مرجع خارجي تفويضًا للكتابة أو يتجاوز المتطلبات المعتمدة.

## الإدماج الأكاديمي والتشغيلي
دُمجت موضوعات الدليل الإضافي الثمانية عشر في الدليل القائم الذي أصبح 38 بابًا، مع ملف HTML موحد مشتق منه. توجد سبعة إجراءات عربية مفصلة تستدعى عند الصلة، و16 بطاقة معيار و80 توصية ضبط هندسية مصاغة للحزمة، لا نقلًا معياريًا مرخصًا. أضيفت عشر مهارات أصلية اختيارية خارج مسارات الاكتشاف التلقائي. لا يلزم BMAD أو Spec Kit أو Addy أو أية إضافة خارجية لتشغيل أدوات الحزمة.

## البيانات والتوافق
أضيف حقلا clarifications وdelivery اختياريًا إلى REQUEST وSTATE، دون إنشاء عقد خامس أو سجل حالة موازٍ. يقرأ الإصدار 1.1 السجلات القديمة غير الممتدة. لا تُفترض قدرة قارئ1.0 على قراءة الحقول الجديدة؛ يلزم اتباع [إجراء الترحيل](../procedures/MIGRATION_1_0_TO_1_1.md) واختبار المضيف والقارئ. المرجع المسجل لقرار أو منح صلاحية ليس إثبات هوية أو تصريحًا تنفذه الأداة تلقائيًا.

أضيف أمر progress للقراءة فقط، يفصل عدد المهام عن معايير القبول، ويعرض نقص الرؤية والتعارض والنتائج الحرجة. لا يستعلم Git أو الخدمات الخارجية ولا يحسب نسبة امتثال كلية. فحص جاهزية السجل يمنع تعارض أدلة النجاح والفشل دون تسوية.

## التصرف في اختبارات الإضافات
أُبقيت اختبارات الأصل الـ127، ونُقلت40 حالة اختبار من أداتي القرار والحساب. استُبدلت اختبارات هيكل الإضافات المنفصلة الثمانية باختبارات تكامل جديدة؛ كانت تتضمن شرط عدم توفر الأصل، الذي لم يعد صحيحًا بعد إرفاقه. بقيت نتائج خطي الأساس أدلة تاريخية مستقلة. لم تُستبدل اختبارات فاشلة بمعايير أضعف.

## حدود الادعاء
الدمج إنشاء مرجع كامل قابل للمراجعة، لا اعتماد المشروع أو النموذج أو المضيف. التحقق البرمجي يثبت السجلات والروابط وحسابات محددة ومسار التنفيذ المحلي الاصطناعي، وليس فهم اللغة الطبيعية أو منع كل أداة. راجع [تقرير التحقق](../verification/REPORT.md) و[حدود الاعتماد](../verification/LIMITATIONS.md).
