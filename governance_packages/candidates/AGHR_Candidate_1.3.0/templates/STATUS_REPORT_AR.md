# قالب تقرير موجز — مثال غير معبأ

**النتيجة:** [ما تم فعليًا، دون ادعاء دمج أو قبول إن لم يحدث].

**المرحلة والفرع:** [المرحلة]؛ [الفرع الحالي أو لا ينطبق]؛ [حدود رؤية البعيد].

**المثبت:** [الفحوص الفعلية ونطاقها ونسخة المرشح]؛ **غير المنفذ:** [ما لم يُفحص ولماذا].

**الخطة والقبول:** [المهام المنجزة/المعلومة]؛ [معايير القبول المثبتة/المنطبقة]؛ [تعريف المقام وحدود القياس، أو غير قابل للحساب].

**الانحرافات والعمل المعلق:** [الحرج أولًا، ثم الفروع أو التبعيات ذات الصلة].

**المطلوب منك تحديدًا:** [قرار واحد أو مجموعة قرارات لازمة مع الخيارات والتوصية]، أو «لا يلزم تدخل حاليًا داخل التفويض القائم».

**الخطوة المسموح بها:** [فعل محدد ونطاقه]، دون وعد بخلفية أو زمن غير مسند.
