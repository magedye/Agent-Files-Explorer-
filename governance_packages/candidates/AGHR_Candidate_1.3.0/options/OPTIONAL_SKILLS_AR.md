# المهارات الاختيارية المقترحة

إحدى عشرة مهارة أصلية غير مفعلة؛ اختيار ما يلزم لا يجعل الضوابط الواجبة على الفعل اختيارية. لا سكربت تثبيت ولا اعتمادية تشغيل على BMAD أو Spec Kit أو Addy. تتكيف الملفات مع المرجعية والمضيف عند التبني.

| المهارة | الغرض | نص المسودة |
|---|---|---|
| الاستيضاح الذكي | طلب غير واضح يؤثر تفسيره في المنتج أو النطاق أو التفويض. | [SKILL.md](../optional_skills/smart-clarification/SKILL.md) |
| المواصفات والتتبع | تطوير ميزة أو مراجعة فجوة بين طلب ومواصفة وتنفيذ. | [SKILL.md](../optional_skills/requirements-traceability/SKILL.md) |
| بدائل التصميم وقراراته | قرار تقني يؤثر في العقود أو المخاطر أو قابلية الصيانة. | [SKILL.md](../optional_skills/architecture-options/SKILL.md) |
| تنفيذ تغيير تدريجي | تنفيذ مصرح لمتطلب واضح قابل للتجزئة. | [SKILL.md](../optional_skills/incremental-change/SKILL.md) |
| تشخيص السبب الجذري | عطل أو فشل اختبار يحتاج تفسيرًا قبل التصحيح. | [SKILL.md](../optional_skills/root-cause-debugging/SKILL.md) |
| التحقق المتناسب مع المخاطر | تقييم مرشح أو تغيير لتحديد ما أثبتته الأدلة. | [SKILL.md](../optional_skills/risk-based-verification/SKILL.md) |
| مراجعة أمن أدوات الوكيل | تمكين أداة أو مهارة أو صلاحية أو اتصال جديد. | [SKILL.md](../optional_skills/agent-tool-security/SKILL.md) |
| جودة المصادر والاسترجاع | إضافة أو تحديث corpus أو فهرس أو مسار إجابة معرفية. | [SKILL.md](../optional_skills/rag-data-quality/SKILL.md) |

| التعلم المحكوم | استخراج الدروس وتصنيف التعليمات بعد تصحيح أو فشل مهم، دون اعتماد تلقائي. | [SKILL.md](../optional_skills/governed-learning/SKILL.md) |

## إجراء الاختيار
حدد الفجوة التي تسدها المهارة، وافحص تعارضها وتكرارها مع الموجود، ثم اخترها صراحة وموائم روابطها وصلاحياتها للمضيف. تحقق من إمكانية تحميلها واستدعائها ومن النتيجة الفعلية. يبقى تمكينها محجوبًا عند غياب التفويض أو ضابط لازم؛ وجود هذا الكتالوج لا يمنحها اعتمادًا.

يمكن البدء بمهارتي الاستيضاح والتتبع إذا كشفت المراجعة حاجة فعلية، ولا يُفرض هذا الاختيار على كل مشروع. معايير التقييم في [خطة الحالات السلوكية](../evaluations/DELIVERY_EVAL_PLAN_AR.md).
