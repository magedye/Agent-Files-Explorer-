# ابدأ هنا — الحزمة المرجعية المحدثة 1.2.0

## ما الذي أفتحه؟
اقرأ [تقرير التسليم](DELIVERY_REPORT_AR.md) لمعرفة التغييرات وحدودها، ثم افتح [الدليل العربي](guide/GUIDE_AR.html) في المتصفح. لا يحتاج الدليل اتصالًا لعرض نصه أو أشكاله؛ روابط الناشرين الخارجية تحتاج اتصالًا. المرجع التفصيلي لا يُحمّل كاملًا في كل جلسة وكيل.

## كيف أستخدمها في مشروع؟
ابدأ بقراءة المشروع وتعليماته وفرعه ومراجعه وتفويضه، ثم طابقها مع [الميثاق](CHARTER.md) والقواعد ذات الصلة. وجود الحزمة لا يجعلها فعالة تلقائيًا. يستخدم التبني [الإجراء الأصلي](START_HERE.md) و[طلب التبني](prompts/ADOPT.md)، ويحافظ على الملفات والتعليمات القائمة.

إذا كان المشروع يستخدم1.0.0 فاتبّع [الترحيل](procedures/MIGRATION_1_0_TO_1_1.md)، ولا تشغّل التهيئة فوق `.aghr` موجود. لا تُنسخ المهارات الاختيارية إلى مسارات التفعيل قبل مراجعتها واختيارها وتأهيلها؛ لا يلزم تثبيت منهجية أو منتج خارجي.

## ما الذي أضيف عمليًا؟
الاستيضاح المؤثر بسؤال وخيارات وتوصية، وتكييف مراحل التطوير، والبدائل، وتأكيد الأثر، والاستمرار ضمن التفويض، ومتابعة الفروع وإغلاقها بأمان، والتسليم الواضح، ومقارنة تقدم الخطة بمعايير المنتج ورصد الانحراف. التفاصيل تصل إليها عبر مدخل المشروع عند الحاجة.

يمكن بعد تهيئة مشروع اصطناعي أو تبنٍّ مصرح به قراءة تقرير السجلات دون تعديلها:

```sh
python runtime/cli.py progress --project /path/to/project
```

هذه قراءة لبيانات المشروع المسجلة وليست فحصًا حيًا لـGit أو للنموذج. صلاحية JSON أو اكتمال المهام ليسا قبولًا للمنتج. نتائج التحقق الحالي في [التقرير](VERIFICATION_REPORT.md)، والتقييم السلوكي الفعلي للمضيف ما زال غير منفذ.

## استخراج الدروس واستثمارها
بعد تصحيح مهم أو إغلاق عمل جوهري، راجع [التعلم المحكوم](procedures/GOVERNED_LEARNING.md): اكتشف الدرس، وثق الدليل والسبب المثبت أو غير المعروف، صنفه وصالحه مع الموجود، ثم نفذ التصرف الذي يغطيه التفويض. المهارة الاختيارية [governed-learning](optional_skills/governed-learning/SKILL.md) تغلف الإجراء دون تثبيت تلقائي. [تقرير التحديث](REFERENCE_UPDATE_REPORT_AR.md) يبين الفرق وحالة المرجع وحدود التحقق.
