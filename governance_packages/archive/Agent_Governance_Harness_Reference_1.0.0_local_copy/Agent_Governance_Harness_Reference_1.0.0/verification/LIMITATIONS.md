# Assurance limits and residual work

The package is an authored final reference with local executable tools. It is not a vendor-certified control framework or a production permission system. Thirty official sources were reviewed on 2026-10-11; mutable product documentation must be checked again for the consumer's exact version. A published desired model behavior is not proof of deployed-model compliance.

The six provider and six host routes are **DOCUMENTED_ONLY**. Live model calls, native Codex/Claude/Gemini/OpenCode/Copilot tests, real credentials, production migrations, external approvals and independent review were **not performed**. The 36 qualification scenarios remain NOT_RUN for real hosts/models. No matrix of 36 provider-host combinations was certified.

The Python executor covers only its three local file operations under a trusted caller and private workspace. It does not contain arbitrary code, race-harden against hostile processes, enforce network egress, authenticate identities or persist replay protection across restarts. Default audit is memory-only. Complete mediation, protected policy/key custody, durable authenticated logs, process isolation, service authorization and operating-system controls must be supplied and tested by the adopter.

Schemas/checkers validate declared structure, relationships and bytes. They cannot prove that a test producer is honest or a decision issuer competent. Inspect actual raw outputs and protect producer identities. A shape-valid empty template is not ready; a recorded EFFECTIVE label does not authenticate itself.

The actual v4 archive has 73 files and 48 active controls. Its 88/441/598 historical records are accounted for, not independently validated against missing originals. This package includes adaptation records, not a copy of every historical original. File/ID coverage is not a semantic-equivalence certificate.

Target compatibility is Python 3.10+ without external dependencies. Only the interpreter/OS actually named in the verification report was tested. Windows/macOS, alternate Python versions, native adapter behavior, HTML rendering across all browsers and accessibility conformance are not implied by one successful Linux run. No external font, script or service is needed for the guide.

Project adoption requires real facts, an applicable decision, configured provider/host, relevant boundary qualification and evidence custody. External canonical-tracker integration is supported as an explicit design extension but no vendor tracker connector is implemented here. Final reference status is separate from consumer effectiveness, product readiness, independent review, release acceptance and activation.
