# OWASP GenAI LLM Top 10 — 2026

**الطبقة التنظيمية:** أمن الأنظمة والوكلاء.

**الانطباق المقترح:** تطبيقات LLM والاسترجاع؛ تاريخ داخل ملف التنزيل يحتاج مصالحة قبل تثبيت مرجع تفصيلي.

## ما تم التحقق منه

الصفحة مؤرخة 2026-08-03. ملف التنزيل الذي عُرض يتضمن حقول تاريخ نشر غير مكتملة؛ إعادة تثبيت النسخة مطلوبة قبل تبني ربط معياري دقيق. [OWASP-LLM](../sources/REGISTER_AR.md)

## ضوابط تطبيقية مقترحة وليست نصوص المعيار

**حدود القراءة:** لم تُنفذ مطابقة بندية شاملة للنص الأصلي. المعرفات REC أدناه من إنشاء هذه الحزمة، وليست أرقام بنود ISO أو NIST أو OWASP. تُربط بضوابط المشروع وبنود النسخة المرخصة عند التبني التفصيلي ولا تُعلن امتثالًا.

### REC-09-01 — التعليمات والمحتوى
افصل المرجع المخول عن محتوى المستخدم أو الوثيقة أو نتيجة الأداة غير الموثوقة.

**الدليل المقترح:** حالات حقن مباشرة وغير مباشرة وحدود تأثيرها.

### REC-09-02 — المعلومات والخرج
قلل كشف المعلومات الحساسة وافحص المخرجات قبل استخدامها كأوامر أو مدخلات تنفيذ.

**الدليل المقترح:** اختبارات تسريب اصطناعي وترميز وتحقق مخرجات.

### REC-09-03 — الوكالة والموارد
احصر الأدوات والميزانيات المحددة وأوقف سلاسل الاستدعاءات غير المنضبطة.

**الدليل المقترح:** سياسة أدوات ومقاييس استهلاك وأدلة رفض.

### REC-09-04 — البيانات والاسترجاع
افحص التسميم وصلاحيات الاسترجاع وعزل المستخدمين في الفهارس.

**الدليل المقترح:** حالات تلوث واختبارات ACL وبيانات مرجعية.

### REC-09-05 — المعلومات الخاطئة
قِس صلاحية الإسناد وعدم اليقين ولا تجعل استشهادًا شكليًا دليل صحة.

**الدليل المقترح:** اختبار علاقة الدعوى بالدليل والامتناع عند نقصه.

## الاعتماد والتحقق

يعين المشروع مالك الضابط وطريقة فحصه وحد قبول ومصدر دليل مناسبين. مصدر الدليل قد يكون تكوينًا أو اختبارًا أو سجل قرار، ولا يكفي التصريح اللفظي بالالتزام. تكون عدم الانطباق والاستثناءات مبررة، ولا تُحوّل إلى نجاح اختبار.

لا يُحزم النص المدفوع أو الكتاب أو دليل الطرف الثالث داخل هذه الحزمة. عند الحاجة لالتزام تعاقدي أو شهادة أو قائمة ضوابط معيارية كاملة، تُراجع النسخة المرخصة والتعديلات النافذة ويجري التدقيق المناسب.
