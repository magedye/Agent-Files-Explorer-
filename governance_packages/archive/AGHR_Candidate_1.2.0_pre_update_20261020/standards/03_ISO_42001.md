# ISO/IEC 42001:2023

**الطبقة التنظيمية:** الحوكمة وإدارة المخاطر والأثر.

**الانطباق المقترح:** نطاق نظام الإدارة المؤسسي المعلن؛ ليست كل متطلبات نظام الإدارة ملفًا داخل المستودع.

## ما تم التحقق منه

نظام الإدارة المؤسسية للذكاء الاصطناعي؛ لا تساوي هذه الحزمة شهادة نظام إدارة. [ISO-42001](../sources/REGISTER_AR.md)

## ضوابط تطبيقية مقترحة وليست نصوص المعيار

**حدود القراءة:** لم تُنفذ مطابقة بندية شاملة للنص الأصلي. المعرفات REC أدناه من إنشاء هذه الحزمة، وليست أرقام بنود ISO أو NIST أو OWASP. تُربط بضوابط المشروع وبنود النسخة المرخصة عند التبني التفصيلي ولا تُعلن امتثالًا.

### REC-03-01 — تحديد النطاق والمالك
حدد ما يغطيه نظام الإدارة ومن يعتمد السياسة ومن يقبل المخاطر.

**الدليل المقترح:** نطاق مؤسسي ومسؤوليات وقرارات مخولة.

### REC-03-02 — سجل الأنظمة والمزودين
احصر نظم الذكاء الاصطناعي وأغراضها ومزوديها ونطاق استخدامها.

**الدليل المقترح:** جرد محدث ومالكون وعقود أو شروط استخدام.

### REC-03-03 — الكفاءة والرقابة
حدد المعرفة اللازمة للمشغل والمراجع ومسار الإشراف والتصعيد.

**الدليل المقترح:** سجل كفاءة وتدريب ومسؤول مراجعة.

### REC-03-04 — المراجعة والتحسين
راجع الحوادث والانحرافات والنتائج واتخذ إجراءات تصحيح قابلة للإغلاق.

**الدليل المقترح:** قرارات مراجعة وإجراءات وأدلة إغلاق.

### REC-03-05 — صدق حدود الادعاء
افصل تأهيل المشروع الفني عن اعتماد أو شهادة نظام الإدارة.

**الدليل المقترح:** تقرير نطاق مع الأدلة المتاحة والالتزامات المؤسسية الباقية.

## الاعتماد والتحقق

يعين المشروع مالك الضابط وطريقة فحصه وحد قبول ومصدر دليل مناسبين. مصدر الدليل قد يكون تكوينًا أو اختبارًا أو سجل قرار، ولا يكفي التصريح اللفظي بالالتزام. تكون عدم الانطباق والاستثناءات مبررة، ولا تُحوّل إلى نجاح اختبار.

لا يُحزم النص المدفوع أو الكتاب أو دليل الطرف الثالث داخل هذه الحزمة. عند الحاجة لالتزام تعاقدي أو شهادة أو قائمة ضوابط معيارية كاملة، تُراجع النسخة المرخصة والتعديلات النافذة ويجري التدقيق المناسب.
