# التحقق المتناسب مع المخاطر

**الحالة:** مهارة أصلية اختيارية، مدمجة في التوزيع وغير مفعلة أو مؤهلة في مضيف. لا تمنح صلاحية ولا تغير مرجعية المشروع. وجود الملف في التوزيع ليس تثبيتًا أو تفويضًا.

## متى تستخدم
تقييم مرشح أو تغيير لتحديد ما أثبتته الأدلة.

## المدخلات
ادعاءات ومتطلبات ومرشح وبيئة وفحوص ودرجة المخاطر.

اقرأ المرجعية الفعلية للمشروع ونطاق التفويض أولًا؛ إذا غابت لا تفترضها. المصدر التفصيلي داخل هذه الحزمة: [الإجراء](../../procedures/PROGRESS_AND_DRIFT_AR.md).

## الخطوات
1. اربط كل ادعاء بدليل مناسب وحدد الفحوص المنطبقة.
2. اختر حالات وظيفية وحدية وسلبية وأمنية بحسب الأثر.
3. نفذ الفحوص الممكنة فقط بعد مراجعة صلاحياتها وأوامرها.
4. سجل الفشل وغير المنفذ والمحجوب دون تحويلها إلى نجاح.
5. افصل نتيجة الاختبار عن الاستقلال والقبول والنشر.

## المخرج
تقرير تحقق مرتبط بالمرشح والبيئة مع فجوات.

## اختبار قبول المهارة عند التأهيل
مدقق JSON ناجح: لا يُسمّى اختبار منع فعل غير مصرح في المضيف.

## الحدود والتوقف
لا تخفف اختبارًا أو متطلبًا لتمرير المرشح.

استخدم الأدوات المتاحة والمصرح بها فقط. سجل ما نفذ فعلًا وما لم ينفذ، ولا تدّع استقلال مراجعة أو موافقة مستخدم أو نشرًا. عند عائق محلي لا توقف عملًا مستقلًا مفوضًا، إلا إذا أمر المستخدم بالتوقف.

## الأصل والتأهيل
تأليف أصلي للحزمة استجابة لطلب المستخدم، دون نقل كود أو نص مهارة من أداة خارجية. حالة التقييم السلوكي: NOT_RUN. اختيارها يحتاج مواءمة المضيف والأدوات واختبارات التحميل والأثر؛ لا تُنسخ تلقائيًا إلى مجلد اكتشاف مهارات.
