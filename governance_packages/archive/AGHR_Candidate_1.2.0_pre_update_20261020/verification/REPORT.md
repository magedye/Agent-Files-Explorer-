## الأسلوب والبيئة
نُفّذت الاختبارات على Python3.13.5 في Linux. استخدمت أدوات التشغيل والتحقق المكتبة القياسية ومساحات مؤقتة. لم تُستخدم مفاتيح API أو حسابات إنتاجية أو مستودعات Git للمستخدم، ولم تُثبّت مهارات أو إضافات أو تغيّر إعدادات مضيف. تحفظ نتيجة فحص صياغة Python3.10 المنفصلة في الأدلة؛ لا تعني تشغيلًا على3.10.

أُعيد عرض HTML ببايتاته الفعلية في Chromium على عرض1440 وعرض390 بكسل. جرى فحص المعرفات والروابط الداخلية وأخطاء الصفحة والطلبات الشبكية وحدود الصفحة؛ العينات البصرية تشمل بداية الدليل وفصل الاستيضاح وبطاقة معيار. الجداول والأشكال قابلة للتمرير داخل حاوياتها على الشاشة الصغيرة. هذا فحص عينات لا شهادة وصولية أو توافق لكل متصفح. لا توجد ملفات خطوط موزعة.

## العيوب التي ظهرت وصُححت
كشف فحص التكامل ثلاثة روابط كانت تشير إلى أسماء قوالب الإضافات قبل مصالحتها؛ صُححت إلى مسارات النسخة المدمجة. في أول تشغيل للاختبارات الجديدة أخفق اختباران متعلقان بتجهيز الاختبار: قرأ أحدهما إصدار التهيئة من ملف المشروع بدل سجل INITIALIZATION الصحيح؛ واستبعد الآخر أدلة تاريخية مطلوبة عند إنشاء نسخة اختبار مؤقتة. أُصلح التجهيز دون حذف الاختبارات أو تخفيف قيود الأصل، ثم نجحت الحالات233. النتائج الفاشلة الأولية محفوظة في `development-tests-first` والمصححة في `development-tests-second`.

أضيف منع صريح لتسوية نجاح وفشل معيار قبول واحد صامتًا عند ادعاء الجاهزية؛ يعرض أمر progress التعارض ولا ينتقي النتيجة المريحة. وأضيفت اختبارات الغموض المؤثر والتوصية بلا سبب والموافقة بلا مرجع والنطاق الكامل بلا خط أساس وملاحظة Git بلا دليل وإغلاق مخالفة بلا إعادة فحص. لا يساوي ذلك مصادقة محتوى تلك السجلات في مضيف فعلي.

## حفظ الأصل ودلالات الدمج
أُبقي الأرشيف الأصلي المرفق دون تعديل. جميع مسارات ملفاته موجودة في النسخة الجديدة؛ الملفات المتغيرة والبايتات المحفوظة مبينة في `compatibility/AGHR_1_0_FILE_DISPOSITION.json`. لم تتغير نسخ `design/frozen/` ولا ملفات `compatibility/V4_*` التاريخية. سجل المدخلات يوثق هويتي الأرشيفين. الدمج هنا دمج محتوى الأرشيف، وليس عملية Git merge.

نُقلت الإرشادات إلى مواضعها ولم تُنسخ سلطة إضافات مستقلة. العقود الأربعة والسجل الواحد ومبدأ مرجعية المطور أولًا محفوظة. الأدلة القديمة موسومة تاريخية. إعادة فحص المصادر في هذه الجلسة شملت29 صفحة رسمية محددة النطاق؛ لا تُنسب مراجعة النصوص المرخصة كاملة أو إعادة تنفيذ تدقيق تاريخي لم يحدث.

## إعادة التحقق وحدود الاعتماد
من جذر الحزمة:

```sh
python tools/check_package.py
python tools/run_tests.py
python runtime/cli.py demo --output /new/isolated/demo-path
```

المسار الأخير يجب ألا يوجد قبل تشغيل العرض. الأمران الأولان يقرآن المرجع ويستخدمان مساحات اختبار مؤقتة؛ لا يتبنيان الحزمة في مشروعك. أداة `init` منفصلة وتحتاج نطاق تبنٍّ مصرحًا.

يجمد `MANIFEST.json` البايتات المرجعية باستثناء ذاته ونتائج التحقق اللاحقة ومخابئ المفسر. بعد ذلك يعاد الفحص والاختبار، ثم يُنشأ ZIP كامل ويفحص بعد استخراجه. نتيجة فحص التوزيع وبصمة الأرشيف ملفان خارجيان لتجنب تضمين بصمة الملف داخل نفسه. سلامة البصمة لا تصادق منشئ الدليل ولا تعني قبول المشروع.
