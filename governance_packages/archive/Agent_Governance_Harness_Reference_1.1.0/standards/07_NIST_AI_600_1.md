# NIST AI 600-1

**الطبقة التنظيمية:** أمن الأنظمة والوكلاء.

**الانطباق المقترح:** تطبيقات الذكاء التوليدي؛ ملف مكمل لإطار المخاطر لا بديل مستقل لكل متطلب.

## ما تم التحقق منه

يوليو 2024؛ ملف مكمل لإطار المخاطر. روجعت مقدمة وأجزاء المخاطر وصورة الصفحة الثامنة، لا تدقيق لكل الإجراءات. [NIST-600-1](../sources/REGISTER_AR.md)

## ضوابط تطبيقية مقترحة وليست نصوص المعيار

**حدود القراءة:** لم تُنفذ مطابقة بندية شاملة للنص الأصلي. المعرفات REC أدناه من إنشاء هذه الحزمة، وليست أرقام بنود ISO أو NIST أو OWASP. تُربط بضوابط المشروع وبنود النسخة المرخصة عند التبني التفصيلي ولا تُعلن امتثالًا.

### REC-07-01 — إسناد الإجابات
اختبر الربط بين الدعوى والدليل والامتناع عند نقصه.

**الدليل المقترح:** حالات إجابات صحيحة وخاطئة وغير قابلة للإسناد.

### REC-07-02 — الاعتماد البشري
حدد القرارات التي تحتاج مراجعة وتجنب إيحاء يقين أو سلطة زائفة.

**الدليل المقترح:** واجهات وتنبيهات وتجارب استخدام لحالات الأثر.

### REC-07-03 — المحتوى والبيانات
افحص الخصوصية وحقوق المصادر وتلوث السياق بحسب الاستخدام.

**الدليل المقترح:** سجل مصادر واختبارات كشف محتوى غير موثوق.

### REC-07-04 — التقييم قبل التمكين
اختبر سوء الاستخدام والفشل وسلامة النظام المتكامل لا النموذج وحده.

**الدليل المقترح:** تقرير تقييم مرشح وبيئة وصلاحيات محددة.

### REC-07-05 — التعامل مع الحوادث
جهز التقاط الحوادث وتصنيفها واحتواءها وتحسين النظام.

**الدليل المقترح:** سجل حادث منزوع الأسرار وإجراء تصحيح.

## الاعتماد والتحقق

يعين المشروع مالك الضابط وطريقة فحصه وحد قبول ومصدر دليل مناسبين. مصدر الدليل قد يكون تكوينًا أو اختبارًا أو سجل قرار، ولا يكفي التصريح اللفظي بالالتزام. تكون عدم الانطباق والاستثناءات مبررة، ولا تُحوّل إلى نجاح اختبار.

لا يُحزم النص المدفوع أو الكتاب أو دليل الطرف الثالث داخل هذه الحزمة. عند الحاجة لالتزام تعاقدي أو شهادة أو قائمة ضوابط معيارية كاملة، تُراجع النسخة المرخصة والتعديلات النافذة ويجري التدقيق المناسب.
