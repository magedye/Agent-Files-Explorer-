# ISO/IEC 25059:2023

**الطبقة التنظيمية:** جودة المنتج والبيانات.

**الانطباق المقترح:** تقييم جودة أنظمة الذكاء الاصطناعي؛ نموذج الجودة لا يحدد عتبة نجاح واحدة لكل الاستخدامات.

## ما تم التحقق منه

نموذج جودة لأنظمة الذكاء الاصطناعي؛ ظهر بديل FDIS قيد الإقرار، لا يُعامل هنا كإصدار منشور ناسخ. [ISO-25059](../sources/REGISTER_AR.md)

## ضوابط تطبيقية مقترحة وليست نصوص المعيار

**حدود القراءة:** لم تُنفذ مطابقة بندية شاملة للنص الأصلي. المعرفات REC أدناه من إنشاء هذه الحزمة، وليست أرقام بنود ISO أو NIST أو OWASP. تُربط بضوابط المشروع وبنود النسخة المرخصة عند التبني التفصيلي ولا تُعلن امتثالًا.

### REC-11-01 — تعريف الجودة
حدد خصائص الجودة المهمة لحالات الاستخدام قبل اختيار المقاييس.

**الدليل المقترح:** عقد جودة ومعايير نجاح واضحة.

### REC-11-02 — تمثيل المهام
اجمع حالات عادية وحدية ولغوية وضارة بحسب نطاق النظام.

**الدليل المقترح:** مجموعة تقييم لها أصل وتقسيم واستخدام معلوم.

### REC-11-03 — جودة النظام لا النموذج فقط
اختبر الإجابة والأداة والاسترجاع والمراجعة البشرية كمسار متكامل.

**الدليل المقترح:** سيناريوهات طرف لطرف مرتبطة بالأثر.

### REC-11-04 — عدم اليقين والتعميم
صرح بحدود التغطية وعدم تعميم نتيجة صغيرة على كل السلوك.

**الدليل المقترح:** تقرير مقاييس ونطاق عينة وفجوات.

### REC-11-05 — المقارنة عبر النسخ
أعد التقييم المتأثر عند تغيير يبدل جودة المنتج أو موثوقيته.

**الدليل المقترح:** خط أساس وفروق تقييم مفسرة.

## الاعتماد والتحقق

يعين المشروع مالك الضابط وطريقة فحصه وحد قبول ومصدر دليل مناسبين. مصدر الدليل قد يكون تكوينًا أو اختبارًا أو سجل قرار، ولا يكفي التصريح اللفظي بالالتزام. تكون عدم الانطباق والاستثناءات مبررة، ولا تُحوّل إلى نجاح اختبار.

لا يُحزم النص المدفوع أو الكتاب أو دليل الطرف الثالث داخل هذه الحزمة. عند الحاجة لالتزام تعاقدي أو شهادة أو قائمة ضوابط معيارية كاملة، تُراجع النسخة المرخصة والتعديلات النافذة ويجري التدقيق المناسب.
