# نطاق التحقق وحدوده

الأوامر الفعلية ونتائجها وعدد اختبارات unittest في `VERIFICATION.json` والسجلات المجاورة. نجاحها يخص الإضافات وأدواتها التوضيحية فقط.

| المجال | ما يغطيه الفحص | ما لا يغطيه |
|---|---|---|
| دالة الاستيضاح | تصنيف أعلام منطقية مُدخلة، رفض نقص الحقول، جمع أسباب التوقف | فهم لغة طبيعية أو صحة علم التفويض أو قرار المستخدم |
| المقاييس | عدادات ومقامات وحالات ومراجع أدلة مقدمة | صحة أو صلاحية أو حداثة المرجع أو شهادة امتثال |
| بنية الإضافات | JSON وروابط محلية ومعرفات وملفات وموانع الادعاء الكامل | تدقيق دلالي شامل أو تحقق حي لكل رابط ويب |
| القراءة البشرية للعرض | فحص عينة عرض HTML عربية | اعتماد وصول أو قراءة كاملة مستقلة لكل المحتوى |
| الأصل | دليل تعذر الوصول فقط | كل قواعده وعقوده واختباراته ومقارنة الانحدار |

الحالات السلوكية للمضيف والنموذج غير منفذة، وتأهيل المهارات غير منفذ، والدمج في الأصل غير منفذ، والاعتماد والنشر غير ممنوحين. ملفات الأمثلة لا تملك أي سلطة تشغيل.

إذا تغيرت الملفات بعد التحقق، راجع الأثر وأعد الفحوص المناسبة، ثم أعد توليد بيان البصمات وسجل التسليم. البصمة تثبت تطابق بايتات فقط، لا اعتماد المصدر أو سلامة المحتوى أو صحة الادعاءات.
