# تشخيص السبب الجذري

**الحالة:** مهارة أصلية اختيارية، مدمجة في التوزيع وغير مفعلة أو مؤهلة في مضيف. لا تمنح صلاحية ولا تغير مرجعية المشروع. وجود الملف في التوزيع ليس تثبيتًا أو تفويضًا.

## متى تستخدم
عطل أو فشل اختبار يحتاج تفسيرًا قبل التصحيح.

## المدخلات
العرض والسجلات المسموحة والنسخة والبيئة والمتوقع.

اقرأ المرجعية الفعلية للمشروع ونطاق التفويض أولًا؛ إذا غابت لا تفترضها. المصدر التفصيلي داخل هذه الحزمة: [الإجراء](../../procedures/LIFECYCLE_AR.md).

## الخطوات
1. ميز خطأ المنتج عن البيئة وعن التبعية وعن اختبار غير صالح.
2. أعد إنتاجًا آمنًا بأقل بيانات وأفعال لازمة ضمن التفويض.
3. ضع فرضيات قابلة للدحض وجمع دليل يفرق بينها.
4. صحح السبب المحدد واختبر منع تكراره والمسارات المجاورة المناسبة.
5. أبلغ السبب المدعوم وما بقي من عدم يقين ولا تدّع نجاحًا بيئيًا غير منفذ.

## المخرج
سبب مدعوم وتصحيح واختبار انحدار أو مانع محدد.

## اختبار قبول المهارة عند التأهيل
فشل بسبب غياب خدمة: لا تغيّر سلوكًا صحيحًا لتمرير الاختبار.

## الحدود والتوقف
لا تعِد محاولات بلا دليل جديد ولا تستخدم بيانات إنتاج بلا إذن.

استخدم الأدوات المتاحة والمصرح بها فقط. سجل ما نفذ فعلًا وما لم ينفذ، ولا تدّع استقلال مراجعة أو موافقة مستخدم أو نشرًا. عند عائق محلي لا توقف عملًا مستقلًا مفوضًا، إلا إذا أمر المستخدم بالتوقف.

## الأصل والتأهيل
تأليف أصلي للحزمة استجابة لطلب المستخدم، دون نقل كود أو نص مهارة من أداة خارجية. حالة التقييم السلوكي: NOT_RUN. اختيارها يحتاج مواءمة المضيف والأدوات واختبارات التحميل والأثر؛ لا تُنسخ تلقائيًا إلى مجلد اكتشاف مهارات.
