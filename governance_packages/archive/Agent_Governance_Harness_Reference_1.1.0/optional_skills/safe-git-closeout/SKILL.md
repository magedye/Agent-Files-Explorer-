# إغلاق Git الآمن

**الحالة:** مهارة أصلية اختيارية، مدمجة في التوزيع وغير مفعلة أو مؤهلة في مضيف. لا تمنح صلاحية ولا تغير مرجعية المشروع. وجود الملف في التوزيع ليس تثبيتًا أو تفويضًا.

## متى تستخدم
إكمال عمل فرع أو تسليم حالة المستودع.

## المدخلات
حالة محلية وبعيدة حيث يمكن فحصها، سياسات الفرع، أدلة وتفويض.

اقرأ المرجعية الفعلية للمشروع ونطاق التفويض أولًا؛ إذا غابت لا تفترضها. المصدر التفصيلي داخل هذه الحزمة: [الإجراء](../../procedures/EXECUTION_AND_GIT_AR.md).

## الخطوات
1. تحقق من الفرع الفعلي وحالة التغييرات والعمل غير المملوك لك.
2. حدد العمل غير المدمج ضمن حدود الرؤية دون الجزم من بيانات قديمة.
3. راجع جاهزية الدمج ودليله والموافقات وحماية الفرع.
4. نفذ فقط الأفعال المفوضة منفصلة، وتحقق من الناتج بعد الدمج إن حصل.
5. زامن وعد إلى الفرع الافتراضي إذا كان مأمونًا ومصرحًا؛ وإلا سلم السبب والخطوة المطلوبة.

## المخرج
تقرير فرع ودمج ومزامنة وفجوات دون أفعال ضمنية.

## اختبار قبول المهارة عند التأهيل
دمج squash: لا تستنتج عدم الدمج من ancestry وحده.

## الحدود والتوقف
لا force push أو حذف فرع أو تغيير worktree يضر عملا آخر بلا تفويض.

استخدم الأدوات المتاحة والمصرح بها فقط. سجل ما نفذ فعلًا وما لم ينفذ، ولا تدّع استقلال مراجعة أو موافقة مستخدم أو نشرًا. عند عائق محلي لا توقف عملًا مستقلًا مفوضًا، إلا إذا أمر المستخدم بالتوقف.

## الأصل والتأهيل
تأليف أصلي للحزمة استجابة لطلب المستخدم، دون نقل كود أو نص مهارة من أداة خارجية. حالة التقييم السلوكي: NOT_RUN. اختيارها يحتاج مواءمة المضيف والأدوات واختبارات التحميل والأثر؛ لا تُنسخ تلقائيًا إلى مجلد اكتشاف مهارات.
