# طلب تبنّي AGHR Minimal 1.1.0

انسخ النص التالي إلى الوكيل الذي يستطيع قراءة مجلد الحزمة والمشروع المستهدف. حدّد مسارهما الفعليين إن لم يكونا معروفين؛ لا توجد مسارات تثبيت مفترضة ولا تعديل تلقائي بمجرد استلام الملف.

```text
تبنَّ AGHR Minimal 1.1.0 لهذا المشروع بوصفها توزيعة وثائقية خفيفة مشتقة من AGHR 1.1.0، دون توسيع الصلاحيات أو استبدال حوكمة قائمة بصورة عمياء.

ابدأ بالقراءة: افحص المسار الفعلي للمشروع وتعليماته القائمة وحالة Git والتغييرات غير المرتبطة والمتطلبات والقرارات والتفويض وحدود الأدوات والبيانات. لا تشغل سكربتًا من الحزمة أو المستودع قبل مراجعته وفهم آثاره.

اقرأ CHARTER.md وCORE.md وregistry/RULES.json كاملًا عند المصالحة الأولى، واستعن بالعقود الأربعة وREFERENCE_MAP.json بحسب الحاجة. الوثائق الرسمية المتوافقة مع نسخة مطور النموذج والمضيف هي المرجع التقني الأول. سجل مصادر الحزمة موروث ولا يثبت حداثته الحالية؛ تحقق من المصدر المتأثر عند اعتماد سلوك تقني متغير.

حدد المتطلبات المغطاة والتعارضات وشروط الانطباق ومستوى الرقابة: STANDARD افتراضيًا، وLITE فقط بأدلة أهلية، وCONTROLLED للحدود المحمية. Minimal ليست إعفاء من التأهيل أو دليلًا على الإنفاذ. لا تخلط التوصيات والمهارات والمعايير بالتفويض.

هذا الطلب يصرح بالتعديلات الوثائقية المحلية الروتينية اللازمة للتبني داخل المشروع المحدد، مع الحفاظ على الموجود. لا يصرح بحذف أو استبدال AGENTS.md أو .aghr أو تغيير الإعدادات العامة أو الصلاحيات أو تثبيت أدوات أو دفع أو دمج Git أو نشر. إذا كانت الحزمة الكاملة معتمدة بالفعل، استخدم Minimal كواجهة موجزة لها ولا تنشئ نسخة معيارية ثانية؛ اربط الأصل نفسه أو حدد صراحة صاحب المرجعية الواحدة.

عالج الغموض بالمصادر المصرح بها أولًا؛ ما بقي مؤثرًا اطرحه مع الخيارات وتوصية وأثر واضح قبل تنفيذه. حافظ على الإجابات السابقة، واستمر في الأجزاء المستقلة المصرح بها. لا تطلب موافقة روتينية سبق منحها، ولا تعتبر السكوت إذنًا.

نفذ أقل تعديل مناسب في موضع التعليمات الفعلي المدعوم بالمضيف، وسجل الإصدار والمصدر وقرار المصالحة والتفويض وحقائق البيئة في سجل المشروع القائم. استخدم القوالب فقط إن لم يوجد سجل معتمد مكافئ. لا تعِد تهيئة مشروع معتمد على 1.0.0 أو 1.1.0؛ سجل الفروق وأوقف الاستبدال المؤثر حتى يحسم.

بعد مراجعة VERIFY.py، شغله محليًا إن توفر Python مدعوم؛ عدم توفره يسجل كفحص غير منفذ ولا يثبت فشل سلوك الوكيل. تحقق على المضيف من تحميل التعليمات ومسارات الصلاحيات ذات الصلة ضمن حدود آمنة. غياب تأهيل لازم يوقف الفعل المحمي لا العمل المستقل.

اختم بنتيجة واضحة: ما تغير، المرجع المعتمد الواحد، الفرع المرصود، الفحوص التي نفذت فعلًا، ما لم يؤهل، والقرار المحدد المطلوب مني. لا تمنح اعتمادًا مستقلًا أو إنتاجيًا، ولا تزعم أن فحص التوزيع أثبت امتثال النموذج.
```
