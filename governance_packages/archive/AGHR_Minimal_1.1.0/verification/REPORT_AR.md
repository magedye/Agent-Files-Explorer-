# تقرير التحقق — AGHR Minimal 1.1.0

## النتيجة والنطاق
أُنشئت توزيعة مصغرة مستقلة الاستخدام من الأرشيف الكامل `Agent_Governance_Harness_Reference_1.1.0.zip` المقدم في هذه المحادثة. لم يُستخدم الإصدار القديم أو ملحق غير مدمج أساسًا، ولم يُعدّل الأرشيف الكامل.

حُفظ السجل المعياري `registry/RULES.json` بالبايت، بجميع القواعد السبع والأربعين ومعرفاتها وقوتها وشروطها والاستثناءات. حُفظ الميثاق وسياسة المصدر وسجل المصادر وملف مستويات الرقابة وقالب عقد المشروع والترخيص بالبايت كذلك. العقود الأربعة وإجراء الاستيضاح حُفظت مضامينها مع تكييف إحالات وحدود التوزيع فقط؛ مواقع التكييف وأصولها وبصماتها مسجلة في [PROVENANCE](../PROVENANCE.json).

لم تُنشأ قاعدة جديدة أو فئة سلطة خامسة. `CORE.md` موجز مشتق، و`REFERENCE_MAP.json` خريطة لا مصدر إلزام ثانٍ. السجل المعياري الأصلي هو الحاكم عند المقارنة ضمن سلطة المضيف والتبني الفعلي للمشروع.

## الفحوص المنفذة
شُغّلت **44 حالة اختبار محلية**: صفر فشل، وصفر أخطاء، وصفر تخطٍ. البيئة الفعلية: **Python 3.13.5 على Linux x86_64**. الدعم المستهدف Python 3.10 أو أحدث، لكنه لم يُختبر هنا على كل إصدارات Python أو Windows أو macOS.

شملت الاختبارات: التوزيع الصحيح، وعدم كتابة المدقق في الملفات، ورمز خروج CLI، وكشف حذف ملف أو إضافة ملف غير مسجل، وكشف تغيير القواعد حتى مع إعادة إنشاء بيان البصمات، ومعرفات القواعد والمصادر، وقوة القاعدة وشروطها، والإحالات المحلية ومرجع الحزمة الكاملة، ورفض مسارات خارج الحزمة والروابط الرمزية وJSON المتكرر المفاتيح، وكشف إضافة ادعاء تبنٍّ أو تأهيل سلوكي غير منفذ.

نتائج الحالات وتواريخ التشغيل وبصمات ملفات موضوع الاختبار في [TEST_RESULTS.json](TEST_RESULTS.json)، والناتج الخام في [TEST_CONSOLE.txt](TEST_CONSOLE.txt). لم تُورث نتائج الاختبارات الـ233 للحزمة الكاملة أو تُحتسب كاختبارات Minimal.

ينفذ `VERIFY.py` سبع مجموعات فحص: بيان البصمات والجرد؛ الملفات المحفوظة والإصدار؛ القواعد ومراجع المصادر؛ خريطة الإحالات؛ صحة JSON؛ روابط Markdown؛ والأصل وحدود ادعاءات التأهيل. نجاحها يثبت هذه الفحوص البنيوية فقط، لا صحة كل تلخيص دلالي ولا امتثال وكيل.

## تخفيف التوزيع
لا تتضمن النسخة المصغرة الدليل الأكاديمي المصور أو الأصول التاريخية، ولا بطاقات المعايير والمهارات الاختيارية، ولا محرك التنفيذ وواجهته ومخططاته ومحولات المضيف. أبقيت مواقع التفاصيل المطلوبة في الحزمة الكاملة موثقة؛ كل مسار مصنف فيها كمرجع للحزمة الكاملة فُحص وجوده فعلًا في أصل 1.1.0 عند الاشتقاق.

هذا الاستبعاد لا يلغي شروط القواعد. عند حاجة قرار إلى تفصيل أو تأهيل غير متاح، يرجع الوكيل إلى المصدر الكامل المطابق أو مرجع معتمد مكافئ، ويتوقف الجزء المتأثر إذا تعذر ذلك بدل اختراع معلومات أو صلاحيات.
