Minimal is derived from the supplied complete AGHR 1.1.0 package. The original [license](LICENSE.md) is retained byte-for-byte. Newly authored Minimal summaries and the distribution verifier follow that permission notice. Source records, original rule records and charter retain their upstream provenance; preserving a record does not independently validate its claims.

The 56 inherited source records in [the source register](sources/REGISTER.json) contain links and bounded summaries. They do not redistribute complete ISO/IEC/IEEE standards, ICRC handbooks, IASC guidance, or external software. The full edition's academic guide, standards cards, optional skills, OWASP-specific adaptations and runtime code are not bundled. No external skill implementation has been copied or activated.

Vendor names and marks remain with their owners. Naming a reference or option is not endorsement, certification, adoption or permission to install. Review the exact license and revision before importing outside material. The source edition's notices identify the consulted Model Spec as CC0 and relevant OWASP materials as CC BY-SA 4.0; underlying publishers' terms still apply to their material. Links and local summaries do not replace licensed text or a competent conformity assessment.

No font files, credentials, personal project state or API keys are included. Python's standard library is used by the optional verifier; no third-party runtime dependency is bundled.
