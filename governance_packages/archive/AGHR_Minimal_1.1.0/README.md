# AGHR Minimal 1.1.0 — النسخة المصغرة

**مشتقة من الحزمة الكاملة AGHR 1.1.0، وليست من إصدار 1.0.0 أو من الإضافات المنفصلة.**
هذه توزيعة وثائقية خفيفة مع مدقق محلي لسلامة التوزيع. تحتفظ بالقواعد السبع والأربعين كاملة وبالعقود الأربعة، وتختصر مسار الاستخدام اليومي. ليست محرك تنفيذ أو عازلًا أمنيًا أو حزمة مهارات مفعّلة.

## البداية
1. فك الأرشيف في مجلد مستقل. اقرأ [CORE.md](CORE.md)؛ وللتبني في مشروع، استخدم [الطلب الجاهز](ADOPT.md).
2. يفحص الوكيل تعليمات المشروع والتفويض والبيئة، ويصالح القواعد قبل إضافة مدخل إلى تعليماته القائمة. لا تستبدل `AGENTS.md` أو `.aghr` القائمين ولا إعدادات المضيف العامة لمجرد فك الأرشيف.
3. بعد التبني استخدم المدخل القصير [AGENTS.md](AGENTS.md) كمرجع يُربط من موضع التعليمات الفعلي الذي يدعمه المضيف، لا كملف يُنسخ فوق الموجود. اقرأ التفاصيل ذات الصلة فقط عند العمل.

**المصغرة تصف حجم التوزيع، وليس مستوى الرقابة.** يبقى STANDARD هو الافتراضي؛ شروط LITE وCONTROLLED محفوظة في [ملفات الرقابة](profiles/README.md). لا تتسع الصلاحيات باختيار أي مستوى.

## ما لم يُضمّن
لا تتضمن Minimal محرك `runtime/cli.py` أو منفذ الأدوات أو مخططات سجلات الحزمة الكاملة أو محولاتها. ولا تشمل الدليل الأكاديمي الكبير، وبطاقات المعايير الست عشرة، والمهارات العشر الاختيارية، والأصول التاريخية والصور أو اختبارات وسجلات الحزمة الكاملة. توجد خريطة مواقعها الأصلية في `REFERENCE_MAP.json`؛ لا تُنزّل أو تُثبّت آليًا.

القواعد الخاصة بالمهارات والمعايير والتأهيل تبقى سارية بحسب الانطباق. عند الحاجة إلى تفاصيل أو إجراء لا يغطيه الموجز، ارجع إلى النسخة الكاملة المطابقة **قبل الفعل المتأثر**، أو إلى مرجع مشروع معتمد مكافئ؛ لا تخترع بديلًا لمفقود. غياب أداة من Minimal لا يُسقط متطلب تحقق أو مراجعة قائمًا.

## الحدود والمرجعية
النصوص الأصلية في `RULES.json` تحتفظ بمسارات شرح وفحص تخص الحزمة الكاملة. هذه المسارات ليست ادعاءً بوجود ملفاتها هنا؛ الخريطة تميز المتاح محليًا عن المرجع الخارجي. لا تنشئ الخريطة قاعدة أو تصريحًا أو فحصًا جديدًا. العقود محفوظة في مضمونها، مع تعديل إحالات وحدود التوزيع فقط.

السجل [sources/REGISTER.json](sources/REGISTER.json) محفوظ من الأصل بمصادره الـ56؛ حالاته وتواريخه **سجل موروث، وليس إعادة تحقق من الويب في إعداد Minimal**. يبقى مرجع مطور النموذج والمضيف المتوافق مع الإصدار مقدمًا تقنيًا وفق الميثاق، ولا يمنح تفويضًا مؤسسيًا أو يحول كل توصية إلى إلزام.

هذه الحزمة غير متبناة في مشروع بعينه. فحص الملفات لا يثبت أن الوكيل قرأها أو امتثل لها، ولا يثبت مصادقة صاحب الصلاحية أو سلامة المضيف. تأهيل المضيف والتقييم السلوكي والمراجعة المستقلة والاعتماد الإنتاجي لم تُنفذ في هذه التوزيعة.

## فحص اختياري محلي
بعد مراجعة السكربت، من داخل المجلد وعلى Python 3.10 أو أحدث:
```sh
python VERIFY.py
python -m unittest discover -s tests -v
```
في Windows يمكن استخدام `py -3` بدل `python` إذا كان هو المشغّل المثبت. المدقق يقرأ ملفات الحزمة المحددة فقط، ولا يثبت تبعيات ولا يتصل بالشبكة ولا يعدّل المشروع أو Git. الاختبارات تستخدم مجلدات مؤقتة لاختبار حالات رفض فساد التوزيع. إصدار Python الذي نُفذت عليه الاختبارات مذكور في التقرير، وليس تأهيلًا لجميع الأنظمة.

البصمات تكشف الاختلاف نسبةً إلى البيان المرفق؛ ليست توقيعًا رقميًا أو إثبات أصالة ضد من يستطيع استبدال الملفات والبيان معًا. احفظ نسخة موثوقة من الأرشيف ومصدره.
