# مرجع تكميلي: ISO/IEC 25010:2023

**الطبقة التنظيمية:** جودة المنتج والبيانات.

**الانطباق المقترح:** جودة المنتج البرمجي المحيط بالنموذج بحسب خصائص المنتج وحاجات المستخدمين.

## ما تم التحقق منه

مرجع تكميلي لجودة المنتج البرمجي المحيط بالنموذج؛ لم يُراجع كامل النص. [ISO-25010](../sources/REGISTER_AR.md)

## ضوابط تطبيقية مقترحة وليست نصوص المعيار

**حدود القراءة:** لم تُنفذ مطابقة بندية شاملة للنص الأصلي. المعرفات REC أدناه من إنشاء هذه الحزمة، وليست أرقام بنود ISO أو NIST أو OWASP. تُربط بضوابط المشروع وبنود النسخة المرخصة عند التبني التفصيلي ولا تُعلن امتثالًا.

### REC-15-01 — الجودة غير الوظيفية
حوّل الأداء والاعتمادية وإمكانية الوصول والاحتياجات الأخرى إلى معايير قابلة للفحص.

**الدليل المقترح:** متطلبات غير وظيفية وحدود قياس.

### REC-15-02 — الاستخدام الحقيقي
اختبر رحلات المستخدم واللغة والواجهة المتاحة بدل الكود فقط.

**الدليل المقترح:** نتائج سيناريوهات استخدام وواجهة.

### REC-15-03 — المفاضلات
وضح أثر تحسين السرعة أو التكلفة على الصحة والخصوصية وسهولة الصيانة.

**الدليل المقترح:** قرار مفاضلة مع دليل ومالك قرار.

### REC-15-04 — صلاحية البيئة
اربط نتائج الجودة ببيئة وبيانات وحمل معلوم.

**الدليل المقترح:** وصف بيئة وقياس قابل للتكرار.

### REC-15-05 — الانحدار
تابع تراجع الخصائص المهمة عند التغيير.

**الدليل المقترح:** مقارنة خط أساس ومرشح وخطة معالجة.

## الاعتماد والتحقق

يعين المشروع مالك الضابط وطريقة فحصه وحد قبول ومصدر دليل مناسبين. مصدر الدليل قد يكون تكوينًا أو اختبارًا أو سجل قرار، ولا يكفي التصريح اللفظي بالالتزام. تكون عدم الانطباق والاستثناءات مبررة، ولا تُحوّل إلى نجاح اختبار.

لا يُحزم النص المدفوع أو الكتاب أو دليل الطرف الثالث داخل هذه الحزمة. عند الحاجة لالتزام تعاقدي أو شهادة أو قائمة ضوابط معيارية كاملة، تُراجع النسخة المرخصة والتعديلات النافذة ويجري التدقيق المناسب.
