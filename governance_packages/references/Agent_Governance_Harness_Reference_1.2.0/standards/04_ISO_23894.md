# ISO/IEC 23894:2023

**الطبقة التنظيمية:** الحوكمة وإدارة المخاطر والأثر.

**الانطباق المقترح:** كل قرار مخاطر يتعلق بتصميم النظام أو استعماله أو تغييره؛ بما يناسب الضرر والسياق.

## ما تم التحقق منه

إرشادات إدارة مخاطر الذكاء الاصطناعي؛ النص الكامل لم يُراجع. [ISO-23894](../sources/REGISTER_AR.md)

## ضوابط تطبيقية مقترحة وليست نصوص المعيار

**حدود القراءة:** لم تُنفذ مطابقة بندية شاملة للنص الأصلي. المعرفات REC أدناه من إنشاء هذه الحزمة، وليست أرقام بنود ISO أو NIST أو OWASP. تُربط بضوابط المشروع وبنود النسخة المرخصة عند التبني التفصيلي ولا تُعلن امتثالًا.

### REC-04-01 — سياق المخاطر
حدد الأطراف المتأثرة والاستخدام المقصود وسوء الاستخدام المعقول.

**الدليل المقترح:** سياق وسيناريوهات آثار قابلة للمراجعة.

### REC-04-02 — عدم اليقين
سجل الافتراضات والفجوات المؤثرة بدل درجات احتمالية مخترعة.

**الدليل المقترح:** سجل افتراضات وأساس التقدير وحدود المعرفة.

### REC-04-03 — معالجة المخاطر
اربط كل خطر بوسيلة منع أو تقليل أو مراقبة ومسؤول واضح.

**الدليل المقترح:** سجل معالجة ودليل ضابط وتاريخ مراجعة.

### REC-04-04 — الخطر المتبقي
اعرض ما لا تعالجه الضوابط وحدد صاحب قرار قبوله.

**الدليل المقترح:** قرار قبول خطر محدد النطاق أو مانع معلن.

### REC-04-05 — إعادة التقييم
أعد التقييم عند تغيير البيانات أو السلوك أو نطاق المستخدمين.

**الدليل المقترح:** سبب إعادة فتح التقييم ونتائجه.

## الاعتماد والتحقق

يعين المشروع مالك الضابط وطريقة فحصه وحد قبول ومصدر دليل مناسبين. مصدر الدليل قد يكون تكوينًا أو اختبارًا أو سجل قرار، ولا يكفي التصريح اللفظي بالالتزام. تكون عدم الانطباق والاستثناءات مبررة، ولا تُحوّل إلى نجاح اختبار.

لا يُحزم النص المدفوع أو الكتاب أو دليل الطرف الثالث داخل هذه الحزمة. عند الحاجة لالتزام تعاقدي أو شهادة أو قائمة ضوابط معيارية كاملة، تُراجع النسخة المرخصة والتعديلات النافذة ويجري التدقيق المناسب.
