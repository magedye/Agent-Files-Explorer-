# ISO/IEC 42005:2025

**الطبقة التنظيمية:** الحوكمة وإدارة المخاطر والأثر.

**الانطباق المقترح:** عندما يكون للنظام أثر على الأفراد أو الفئات أو المجتمع؛ يحدد عمق التقييم وفق السياق.

## ما تم التحقق منه

تقييم أثر أنظمة الذكاء الاصطناعي عبر دورة حياتها؛ النص الكامل لم يُراجع. [ISO-42005](../sources/REGISTER_AR.md)

## ضوابط تطبيقية مقترحة وليست نصوص المعيار

**حدود القراءة:** لم تُنفذ مطابقة بندية شاملة للنص الأصلي. المعرفات REC أدناه من إنشاء هذه الحزمة، وليست أرقام بنود ISO أو NIST أو OWASP. تُربط بضوابط المشروع وبنود النسخة المرخصة عند التبني التفصيلي ولا تُعلن امتثالًا.

### REC-06-01 — من يتأثر وكيف
حدد المتأثرين المباشرين وغير المباشرين والاستخدام الفعلي.

**الدليل المقترح:** خريطة أصحاب مصلحة ومسارات أثر.

### REC-06-02 — الفائدة والضرر
قارن منافع النظام بضرره المحتمل وبدائل أقل أثرًا.

**الدليل المقترح:** مقارنة بدائل وسيناريوهات موثقة.

### REC-06-03 — الأثر التفاضلي
اختبر ما إذا كانت فئات أو لغات أو حالات ضعف تتحمل مخاطر مختلفة.

**الدليل المقترح:** تقييم حالات ممثلة مع حدود العينة.

### REC-06-04 — المشاركة والتظلم
حدد وسيلة مناسبة للتغذية الراجعة والتصحيح البشري للقرارات المؤثرة.

**الدليل المقترح:** قناة تواصل ومسؤول تصحيح وسجل معالجة.

### REC-06-05 — تحديث التقييم
أعد النظر عند تغير الاستخدام أو الجمهور أو صلاحيات النظام.

**الدليل المقترح:** إصدار تقييم جديد مرتبط بالتغيير.

## الاعتماد والتحقق

يعين المشروع مالك الضابط وطريقة فحصه وحد قبول ومصدر دليل مناسبين. مصدر الدليل قد يكون تكوينًا أو اختبارًا أو سجل قرار، ولا يكفي التصريح اللفظي بالالتزام. تكون عدم الانطباق والاستثناءات مبررة، ولا تُحوّل إلى نجاح اختبار.

لا يُحزم النص المدفوع أو الكتاب أو دليل الطرف الثالث داخل هذه الحزمة. عند الحاجة لالتزام تعاقدي أو شهادة أو قائمة ضوابط معيارية كاملة، تُراجع النسخة المرخصة والتعديلات النافذة ويجري التدقيق المناسب.
