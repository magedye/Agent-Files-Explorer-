# ISO/IEC 5338:2023

**الطبقة التنظيمية:** المرجعية الهندسية ودورة الحياة.

**الانطباق المقترح:** مشروع يبني أو يدمج أو يشغّل نظام ذكاء اصطناعي؛ يتكيف للمكونات الجاهزة ولا يفترض تدريب نموذج جديد.

## ما تم التحقق منه

دورة حياة أنظمة الذكاء الاصطناعي. النص المعياري الكامل لم يُراجع. [ISO-5338](../sources/REGISTER_AR.md)

## ضوابط تطبيقية مقترحة وليست نصوص المعيار

**حدود القراءة:** لم تُنفذ مطابقة بندية شاملة للنص الأصلي. المعرفات REC أدناه من إنشاء هذه الحزمة، وليست أرقام بنود ISO أو NIST أو OWASP. تُربط بضوابط المشروع وبنود النسخة المرخصة عند التبني التفصيلي ولا تُعلن امتثالًا.

### REC-01-01 — تعريف حدود النظام
ميّز النموذج المستضاف والكود والبيانات والأدوات والبشر وحدود مسؤولية كل طرف.

**الدليل المقترح:** خريطة نظام ومسؤوليات واعتماديات.

### REC-01-02 — ربط المراحل بالأدلة
اربط قرارات المتطلبات والتصميم والتكامل والتشغيل بأدلة انتقال مناسبة.

**الدليل المقترح:** سجل دورة حياة مع روابط لمخرجات المراحل.

### REC-01-03 — تغيير النموذج أو المعرفة
صنف أثر تغيير المزود أو نموذج أو فهرس على سلوك النظام وأعد التقييم المتأثر.

**الدليل المقترح:** مقارنة نسخ وخطة تقييم قبل وبعد.

### REC-01-04 — المراقبة والتحسين
حدد ما يستدعي مراجعة السلوك أو إيقاف أداة أو تصحيح معرفة وفق الضرر المتوقع.

**الدليل المقترح:** مقاييس وأحداث تنبيه وإجراء تدخل مؤهل.

### REC-01-05 — نهاية الخدمة
خطط لإلغاء الوصول وإدارة السجلات والبيانات والنسخ عند تقاعد المكون.

**الدليل المقترح:** خطة إيقاف ومسؤول احتفاظ وإثبات تنفيذ مصرح.

## الاعتماد والتحقق

يعين المشروع مالك الضابط وطريقة فحصه وحد قبول ومصدر دليل مناسبين. مصدر الدليل قد يكون تكوينًا أو اختبارًا أو سجل قرار، ولا يكفي التصريح اللفظي بالالتزام. تكون عدم الانطباق والاستثناءات مبررة، ولا تُحوّل إلى نجاح اختبار.

لا يُحزم النص المدفوع أو الكتاب أو دليل الطرف الثالث داخل هذه الحزمة. عند الحاجة لالتزام تعاقدي أو شهادة أو قائمة ضوابط معيارية كاملة، تُراجع النسخة المرخصة والتعديلات النافذة ويجري التدقيق المناسب.
