# ISO/IEC 27001:2022

**الطبقة التنظيمية:** أمن الأنظمة والوكلاء.

**الانطباق المقترح:** نظام أمن المعلومات ونطاق أصوله والتزاماته المؤسسية المعلنة.

## ما تم التحقق منه

نظام إدارة أمن المعلومات؛ لم يُراجع نص المتطلبات أو الملحق كاملًا، ولا كل التعديلات المنطبقة. [ISO-27001](../sources/REGISTER_AR.md)

## ضوابط تطبيقية مقترحة وليست نصوص المعيار

**حدود القراءة:** لم تُنفذ مطابقة بندية شاملة للنص الأصلي. المعرفات REC أدناه من إنشاء هذه الحزمة، وليست أرقام بنود ISO أو NIST أو OWASP. تُربط بضوابط المشروع وبنود النسخة المرخصة عند التبني التفصيلي ولا تُعلن امتثالًا.

### REC-10-01 — الأصول والتصنيف
احصر البيانات والأسرار والخدمات وأصحابها وحدود الوصول.

**الدليل المقترح:** جرد أصول وتصنيف بيانات ومالكون.

### REC-10-02 — إدارة الوصول
طبق أقل امتياز وفصل المسؤوليات على بيئة التشغيل والتطوير.

**الدليل المقترح:** مصفوفة صلاحيات وأدلة اختبار ومسار إلغاء.

### REC-10-03 — الأسرار والسجلات
امنع إدراج الأسرار في المخرجات والأدلة وحدد احتفاظًا مناسبًا.

**الدليل المقترح:** سياسة أسرار وفحوص اصطناعية وسجل وصول.

### REC-10-04 — المورد والحادث
قيّم الأطراف الخارجية وجهز الاستجابة للحوادث والتعافي.

**الدليل المقترح:** تقييم مزود وخطة حادث وتعافٍ مجربة ضمن النطاق.

### REC-10-05 — اختيار الضوابط
اربط الضوابط بالمخاطر والانطباق ولا تدّع تغطية الملحق المعياري من هذه البطاقة.

**الدليل المقترح:** سجل انطباق فعلي ومراجعة النص المرخص عند التدقيق.

## الاعتماد والتحقق

يعين المشروع مالك الضابط وطريقة فحصه وحد قبول ومصدر دليل مناسبين. مصدر الدليل قد يكون تكوينًا أو اختبارًا أو سجل قرار، ولا يكفي التصريح اللفظي بالالتزام. تكون عدم الانطباق والاستثناءات مبررة، ولا تُحوّل إلى نجاح اختبار.

لا يُحزم النص المدفوع أو الكتاب أو دليل الطرف الثالث داخل هذه الحزمة. عند الحاجة لالتزام تعاقدي أو شهادة أو قائمة ضوابط معيارية كاملة، تُراجع النسخة المرخصة والتعديلات النافذة ويجري التدقيق المناسب.

## تنبيه الإصدار والتعديل
صفحة الناشر التي أعيد فحصها عند الدمج تسرد ISO/IEC 27001:2022/Amd 1:2024. يجب تقييم انطباق التعديل مع النسخة المعتمدة؛ لم ينفذ تدقيق بندي لنص التعديل هنا. [ISO-27001](../sources/REGISTER_AR.md)
