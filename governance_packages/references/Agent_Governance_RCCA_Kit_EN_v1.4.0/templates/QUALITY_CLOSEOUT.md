# Quality closeout — attach to the existing task record

**Outcome / actual changes:**
**Requirements:** stable IDs, implementation and actual verification evidence; outstanding items.
**Gaps:** MISSING / PARTIAL / CONTRADICTS / UNREQUESTED / UNVERIFIED, existing task references.
**Original bug symptom:** before/after observation and regression evidence when applicable.
**Documents:** completeness, consistency, accuracy, traceability, clarity, currentness, non-duplication in scope.
**Review:** SELF or evidenced separated review; identity, scope and limits; no self-granted independence.
**Implementation correctness confidence:** evidence-backed level and remaining uncertainties, not a success probability.
**Recovery:** performed, rehearsed, planned, failed or NOT_RUN; never imply an irreversible effect was undone.
**Status:** implemented / tested / verified in scope / owner acceptance / activation separately.
**Necessary next decision:** only material unresolved authority or acceptance.

Do not conceal failed tests, change acceptance to fit code, or turn a metadata-ready result into DONE.
