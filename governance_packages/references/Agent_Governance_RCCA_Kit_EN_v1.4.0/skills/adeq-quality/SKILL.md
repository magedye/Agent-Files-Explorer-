# ADEQ quality — optional reference skill

This skill is shipped but NOT INSTALLED or activated. Preserve resource references when
adapting it to a host; do not copy SKILL.md alone and assume its dependencies exist.
Resources below are relative to this bundled skill folder. Locate the kit root first.

1. Identify task scope, original request, actual authorization and already selected skills.
2. Read [Core](../../policies/CORE.md). Select only the relevant sections of
   [workflows](../../workflows/QUALITY_WORKFLOWS.md) and [ADEQ](../../policies/ADEQ.md).
3. Resolve consequential uncertainty from repository evidence, or give the owner options,
   a recommendation and the smallest necessary question. Continue independent work.
4. Use QUICK/STANDARD/CONTROLLED; analyze important impacts, confidence and recovery.
5. Implement only when the user requested implementation and existing scope allows it.
6. Review semantic requirement/document consistency, preserve task IDs and perform actual
   verification. Classify remaining gaps and disclose independence and evidence limits.
7. Use the optional read-only CLI only when a declared diagnostic snapshot is useful;
   consult [contracts](../../docs/13_QUALITY_CONTRACTS.md). Do not mistake a green metadata
   check for correct code, authenticated permission or acceptance.

For review-only requests, return findings without modifying files. No network, installer,
subagent, runtime hook or provider-specific permission is required by this skill.
