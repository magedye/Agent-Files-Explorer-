## OpenAI / Codex

The directly retrieved Model Spec edition is dated 2025-12-18. Its authority, scoped
autonomy, side-effect, untrusted-data and uncertainty principles informed this release.

itself a native role. Same-authority message handling and project-document approval are
not interchangeable questions. No access to hidden system/developer content is requested.

present does not prove the current session loaded it. Verify the actual host/version and
available session metadata before relying on discovery. The optional skill is not installed
or enabled by this delivery; moving it without reconciling relative resource paths can break it.

## Spec Kit: adapted method, not copied runtime

The reviewed documentation describes clarification, checklist quality, read-only cross-
artifact analysis and convergence. We retain those ideas with project-specific authority.
The inspected converge template can append new tasks and invoke extension hooks; this
kit does neither. It reuses existing task IDs and produces read-only proposals, and adds
UNVERIFIED as an explicit quality gap. Fixed filenames, repeated task append behavior,
automatic hooks and a second constitution are deliberately not imported.

No Spec Kit source code or command templates are bundled. The workflow text and diagnostic
code here are original adaptations of the supplied plan; installation, licensing review of
any future imported code and direct CLI compatibility remain separate tasks.
