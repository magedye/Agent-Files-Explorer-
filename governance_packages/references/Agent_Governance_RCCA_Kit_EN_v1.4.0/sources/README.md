# Source provenance and currency

SOURCE_REGISTER.json records selected official sources and exactly what was retrieved. INPUT_MANIFEST.json records
immutable user-provided inputs. LEGACY_MANIFEST.json records unchanged compatibility files. The source register is
an engineering bibliography, not an authoritative policy feed or complete reproduction of provider documents.

Source retrieval was not uniform: direct and indexed views differed for parts of Codex/OpenAI documentation.
The new Model Spec announcement was found, but its complete versioned text was not retrieved. These limits are
material and remain open. No latest-full-text certification is claimed. Provider/host documents can change; repeat
only relevant checks before project adoption. A project rule never overrides actual higher-priority instructions.

No public-source text archive is bundled. Summaries are narrow; consult the official URLs for full meaning.
Local Arabic filenames in INPUT_MANIFEST are provenance identifiers; operational instructions and code are English.
