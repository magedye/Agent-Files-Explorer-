# مراجعة ذاتية محددة النطاق — استكمال العقود

**النوع:** `SCOPED_SELF_REVIEW`، وليست مراجعة مستقلة أو قبول إصدار. تطبق محاور الصحة والوضوح والمعمارية والأمان والموارد في مهارة code-review-and-quality.

| المحور | ما روجع | النتيجة وحدها |
| --- | --- | --- |
| الصحة | العمليات مقابل النص، الأنواع والأغلفة، EXCEPTION، تعدد التأهيل، الإقرار الخام، قيود النجاح، الحالة والقياسات | تعريف كامل؛ أمثلة JSON مستقلة ورفض المدخلات والنجاح غير المطابق؛ لا ادعاء لنتيجة AGHR الفعلية |
| الوضوح | فصل مخططات القراءة والتغيير والتنفيذ، وفهرس العمليات عن الملف المولد | مصدر واحد لتوليد OpenAPI وأغلفته، دون نسخ منطق الحوكمة إلى الجسر |
| المعمارية | CI وحده ناشر الحالة، مصدر الأدلة للقراءة، wrapper kind مستقل، 12 جدولًا | التعريف يحافظ على حدود المصدر والمشتقات؛ التنفيذ الفعلي لهذه الحدود غير مشغل |
| الأمان | هوية الخادم، خانة الدور، If-Match، الإقرارات، حفظ المدخل الأجنبي | رفض بنيوي للحقول المزورة؛ التفويض وإثبات المصدر وتطابق الأدلة بوابات فعلية لا يغطيها هذا الفحص |
| الموارد | حدود المحلل، التكرار، UTF-8، lookup وضوابط العمليات | التسلسل المحلي محدود ومختبر؛ timeout/ذاكرة/شجرة عمليات المضيف لا تزال NOT_RUN |

## الملاحظات التي عولجت

1. تعريف JSON عام عودي كشف حدًا في محول Test-Json؛ بُسّط إلى مجموعة أنواع JSON نفسها دون تغيير دلالة القبول. أصبح الفاحص يرفض أخطاء محول المخطط صراحة بدل احتسابها رفضًا صحيحًا لعينة سالبة.
2. جمع موارد المخططات يحفظ أسماء خصائص `$schema` والقيم JSON الحرفية؛ لا يعيد تفسيرها كمراجع. يوجد اختبار انحدار لذلك.
3. غياب submit من قائمة API عولج بإضافة معلنة من سير §37؛ لا تسجل على أنها إحدى العمليات الأصلية الـ58.
4. اختلاف الإيحاء بين §7.1 و§14.2 عولج بعقد إقرار خام مستقل، مع إبقاء شرط التنفيذ الأشد لـHOST_SIGNAL. لا تعديل للمصدر أو توليد دليل وهمي.
5. تحفظ النسخة السابقة ذات عمليات GET الأربع في إيصال الاستكمال، ولا تبقى عقدًا نشطًا منافسًا.
6. لم يُستخدم typed state أو declared role أو schema PASS بصفته تفويضًا أو إثبات تشغيل. معايير المحرك والمضيف منفصلة ومطلوبة.

## دليل التحقق

[إيصال الاستكمال](../../evidence/studio-contracts-completion-2026-10-22/README.md) يسجل المرشح وبصماته والأوامر ونتائجها الفعلية، بما فيها المحاولات السابقة. فحوص OpenAPI المحلية هي تطابق الجرد والتوليد الحتمي والمراجع وأمثلة أنواع البيانات؛ لم يُشغّل مدقق OpenAPI خارجي أو خادم HTTP/متصفح لهذا العقد. لا تثبيت مكتبات أو محرك مفترض، ولا تعديل شيفرة التطبيق أو الحزم المرجعية.
