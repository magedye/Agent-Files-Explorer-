## التغطية والمقارنة

[مصفوفة التغطية](../../evidence/last-app-adoption-2026-10-21/COVERAGE.md) تربط أقسام Studio الاثني عشر السابقة وجميع معايير القبول الـ36 بالنسخة المحدثة. حُفظت أقسام مرجع AGHR الـ18 وملاحقه الستة؛ فروقه تحريرية فقط. حُفظت جميع أعمدة الجداول السابقة الـ126 مباشرة أو بتحويلات موثقة في G.2، وتوسعت معايير القبول إلى 31 وظيفيًا و13 غير وظيفية.

راجع [سجل الاعتماد وحالتي قبل/بعد](../../governance/LAST_APP_ADOPTION_2026_10_22.md)، و[الفرق عن مواصفة Studio السابقة](../../evidence/last-app-adoption-2026-10-21/studio-before-after.diff)، و[الاستكمال فوق نص last-app الأصلي](../../evidence/last-app-adoption-2026-10-21/studio-selected-to-integrated.diff). تمت معالجة متطلبات compact، الحوكمة الذاتية، الأدلة ومعايير التحقق، وفصل دور المضيف عن AGHR، وإعادة استخدام التطبيق الحالي.

## حدود الاعتماد والخطوة التالية

هذا اعتماد **تصميم ومتطلبات**. تنفيذ التصميم الجديد لم يبدأ، ولا يمنح اعتماد مضيف أو مراجعة مستقلة أو قبول إصدار. يبقى مرجع التشغيل 1.2.0 وافتراضي التطبيق `aghr_1_2_0`، والمرشح 1.3.0 في حالته المستقلة.

Phase 0 هي الخطوة المقترحة التالية: حسم أسئلة العقود الموروثة في G.4، ثم العرض الأول للقراءة فقط دون أي كتابة من Studio إلى القرص. أسماء الحزم وأوامر التوزيع والأرقام التوضيحية في التصميم ليست إثباتًا لوجود توزيع أو ميزة منفذة.

أُرشفت المدخلات المختارة والنسخة المعتمدة السابقة ببصماتها في [أرشيف التصميم](../../../governance_packages/archive/studio-designs-2026-10-21/README.md). هذه الوثائق هي مسار التطوير المعتمد؛ الأرشيف يحتفظ بالتاريخ، وINBOX مخصص للوارد الجديد.
