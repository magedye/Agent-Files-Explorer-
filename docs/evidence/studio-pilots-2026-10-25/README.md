## المحاولات المرفوضة والتوافق

- عارض Git CRLF غيّر البايتات عن CP، فحُجب التبنّي. [قبل/بعد الإصلاح](CRLF_REPAIR/REPAIR.json) يحفظ الأصل، وضُبط LF في المستودعين فقط؛ لم يلغ اختبار البصمة.
- انتهى دفع محلي بمهلة أثناء hook كثيف العمليات. فُحصت حالة Git الفعلية: وصل الدمج إلى المستودع المحلي، لكن **لم تكتب حالة**. اختُصر التحقق في hook إلى ربط التوقيع بمعرف commit وشجرته غير القابلة للتغيير، واستخدم Git التنفيذي المطلق في البيئة المقيدة، ثم أعيد فحص المصادر والدفع ودمج محاولة CI جديدة. التقرير الفاشل لم يستبدل.
- أُصلح مسار استئناف CP الذي قرأ شكل artifact بصورة خاطئة؛ بقي CP المعتمد وتاريخه محفوظين.
- [Sentinel الأول](../studio-t36-2026-10-25/browser-1792930311362/ACCEPTANCE.json) فشل في الاختبار: أربع إشعارات metadata لمجلدات `.aghr`/`ci-private` أثناء إنشاء ملفات Draft/المتصفح، مع ثبات جميع البصمات. التقرير النهائي يفصل هذه الإشعارات عن أحداث ملفات المصدر/state/runtime، التي يستمر منعها. لا تحويل للفشل السابق إلى PASS.
