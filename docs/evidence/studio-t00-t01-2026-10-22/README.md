## ما أثبته الاستدعاء

الأمر الموجود هو Python مع `runtime/cli.py` داخل 1.3.0. مساعدة validate تعرض `--project` و`--ready`؛ لا تمثل تحقق rc.3 الصارم. [stderr التشخيص الفعلي](cli-probes/legacy-strict-parser.stderr.txt) يصرح `unrecognized arguments: --strict`، و[مساعدة السطح الفعلي](cli-probes/legacy-root-help.stdout.txt) تعرض الأوامر العشرة. جميع stdout/stderr الأصلية محفوظة وبصماتها في القطعة 02.

تسجل [بيئة Python](PYTHON_ENVIRONMENT.json) الإصدار والبصمة وفحص بيانات توزيع aghr/aghr-studio دون استيراد محرك أو تثبيته؛ وفحصت [بيانات user-site صراحةً](USER_SITE_METADATA.json) دون تفعيلها، ولم يظهر التوزيعان فيها. يوثق [اكتشاف الأوامر](COMMAND_DISCOVERY.json) غياب الأسماء من PATH. لوحظت ثلاثة أوامر تعرف داخل loop في parser؛ أضيفت من --help الفعلي بدل الاكتفاء باستخراج literals، وحفظت النسخة الأولية في `02_CLI_SURFACE.initial.snapshot`.

استُخدمت معاملات منظمة وshell=false وWindows hidden و`-I -B -X utf8`، مع مهلة التقاط محدودة. لم تشغل أجسام eval/qualify أو init/adoption أو كاتب الحالة القديم. هذه الاحتياطات لا تؤهل محول حدود الموارد المطلوب في T15، ولا تثبت بوابة عرض Phase 0 الخالي من الكتابة.
