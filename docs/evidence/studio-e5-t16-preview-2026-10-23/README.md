# تسليم E5 وT16 ومعاينة T17

**النطاق:** اعتمد المالك T13–T15 وفوّض E5 لمعالجة المقترحات، ثم إكمال دورة T16 وبدء T17 كمعاينة. لا اعتماد إصدار أو ترقية مرجع أو إذن تصدير نهائي.

**النتيجة المحلية:**80/80 اختبارًا،8/8 تجارب CLI، وEdge معزول/Sentinel ناجحان؛1719 تحققًا للأدلة والبصمات و19 تحققًا للعقود. البناء ناجح مع تحذير حجم الحزمة الرئيسية القائم؛ السياق والروابط0 أخطاء/0 تحذيرات. [نتائج التحقق](VERIFICATION.json).

## المنجز

| الجزء | التنفيذ والدليل |

| إبطال النتائج | تعديل البصمة يبطل checks/generation/approvals ذريًا، ويحتفظ بالقرار السابق والفاعل والسبب والوقت والبصمة في التاريخ. فشل audit يتراجع عن المعاملة؛ المنحة المستهلكة لا تعود صالحة. اختبار الموافقات يستخدم سجلًا مستوردًا **IMPORTED_TEST_ONLY** في SQLite معزولة؛ لا موافقة T18 منتَجة. |
| T17 | محرك Python ومعاينة API/واجهة: full/compress/compact/fail، ميزانية UTF-8 وحفظ P0. فحص PRIN-007 بنصه الحاكم عند L1+؛ وجود الاسم وحده مرفوض. [الحالات](GENERATION_CASES.json). |

فحص المقترح الرصدي الصحيح يرجع `VALID / exit 0`. البند الإلزامي غير المثبت يحتفظ بـ`AUTHORITY_SOURCE_UNVERIFIED / BLOCKED / exit 3`؛ لا Mock ولا منح سلطة ذاتية. نجاح عرض PRIN-007 في معاينة لا يعتمد مصدر سلطته أو يرحله إلى Active.

## الحدود والخطوة التالية

T16 مكتملة تقنيًا ضمن Draft بحسب الاختبارات؛ لا ندعي قبول مالك جديد أو مراجعة مستقلة. T17 بدأت بالمعاينة فقط، وليست إغلاق E3 كاملًا: lookup الحقيقي `NOT_RUN`، ونجاح compact في التركيب الاختباري ليس تأهيلًا للمضيف. لا export أو clipboard/download أو AGENTS.md على القرص، ولا تعديل للمرجع1.2.0 أو state.json/runtime_evidence. القيم المؤقتة للمالك والترخيص باقية بموافقة المالك.

فحوص E4 السبعة **REQUIRED / NOT_RUN / NOT_WAIVED**. لا eval/qualify فعليين؛ محول T15 محفوظ وملزم عند تشغيلهما لاحقًا. المعايرة وdoctor وCI والنشر بوابات منفصلة. الخطوة التالية المقترحة: استكمال E3 الحقيقي وT18 وفق نطاق صريح قبل أي تصدير.

للتشغيل ومسارات API: [Studio Draft mode](../../features/STUDIO_DRAFT_MODE.md). مصدر JCS المرجعي: [RFC8785](https://www.rfc-editor.org/rfc/rfc8785)؛ التثبيت والحدود مثبتان في امتداد Python، وليس منطق تحقق مكررًا في Node.
