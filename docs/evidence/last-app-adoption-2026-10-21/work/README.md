# نسخ عمل محفوظة ضمن الأدلة

هاتان نسختا إعداد وسيطتان، تطابقان ملفي التصميم المعتمدين عند إغلاق هذا العمل. المرجعية الوحيدة الحالية هي [مدخل التصميم المعتمد](../../../specs/aghr-rc3/README.md)، وسجل القرار والبصمات فيه.

احتُفظ بنسختي العمل لأن المراجعة الآلية رفضت أمر التنظيف برسالة `blocked by policy` دون تعليل أكثر تحديدًا. لم تُعاد محاولة الحذف بطريقة أخرى. لا يحول وجودهما ضمن الأدلة هذا المجلد إلى خط أساس أو مرشح إضافي.
