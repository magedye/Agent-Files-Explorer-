# حفظ ورفع أعمال Studio وE1

طلب المالك حفظ التغييرات ورفعها. يوثق [سجل الحفظ](CHECKPOINT.json) نطاق العمل وحالة البصمات قبل commit؛ يحدد Git والمستودع البعيد نتيجة الرفع الفعلية.

- تطابقت ملفات مصدر E1.d الثلاثة والثلاثون مع SOURCE_PIN، وتطابقت مخرجات AFTER البالغ عددها 109 ملفات قبل إعداد الحفظ.
- الاختبارات المحفوظة على المصدر نفسه: المرشح 63/63 والتطبيق 41/41؛ لم تعد لمجرد الحفظ. يرفق فحص البايتات المرحّلة وصحة السياق عند الحفظ.
- فرق الحفظ الوحيد في الملفات السابقة هو توسيع حفظ البايتات في .gitattributes لملفات محددة مرتبطة بالإيصالات؛ إعداد core.autocrlf=true كان يغير بايتات بعضها عند الترحيل. [الحالة السابقة](gitattributes.before.snapshot) محفوظة؛ المحتوى والبصمات السابقة لم تعدل.
- E1 مكتملة تقنياً وتنتظر اعتماد مخرجاتها. E2 وT02 غير مبدوءتين، وT01 محجوبة. المالك والترخيص مؤقتان؛ المرجع الافتراضي 1.2.0. لا يتضمن الحفظ اعتماداً أو نشراً للحزمة.
- [قائمة الملفات وبصماتها](FILES.json) تسجل اللقطة السابقة لفرق attributes. [فحص الحفظ](STAGING_CHECKS.json) يثبت مطابقة ملفات Git المرحّلة، وتبقى البصمات والأدلة السابقة محفوظة.
