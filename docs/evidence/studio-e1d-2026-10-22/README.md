# تسليم E1.d — الفهرس المحمول وإغلاق المخططات

**التاريخ:** 2026-10-22. **المسار:** B فقط. **النتيجة التقنية:** `IMPLEMENTED_AND_TESTED`.

أُنجز إخراج الفهرس وإغلاق نسخ schemas داخل المرشح نفسه. أصبحت أعمال E1.a–d التقنية مكتملة لنطاق القراءة والفهرسة؛ **اعتماد المالك لمخرجات E1 الحالية ما زال مطلوبًا قبل الانتقال الرسمي إلى E2**. لم تبدأ E2، وتبقى T01 `BLOCKED_NOT_CLOSED` وT02 غير مبدوءة.

أقر المالك القيم المؤقتة للمالك والترخيص لاستمرار E1 دون انتظار توقيع نهائي. تبقى `PROVISIONAL_OWNER_LICENSE` و`LICENSE` وmanifest الفعلي محفوظة ببايتاتها؛ التوقيع الرسمي مطلوب لاحقًا في مساره. يحفظ [التوجيه الحالي](OWNER_DIRECTIVE.json) هذا التفويض وحدوده.

## نقل الفهرس وحدود الحكم

`catalog` أمر قراءة محلي إضافي ضمن المسار B. انتقل **البروتوكول الداخلي من 1 إلى 2** لتسمية READ وإضافة بيانات الفهرس صراحةً. حفظت نسخة 1 في snapshot السابق والفروق؛ الجسر المستقبلي T02 يحتاج استهلاك النسخة الصريحة. لم تتغير contract.1 أو الواجهة أو ملفات التطبيق والخادم.

خرج [الفهرس الفعلي](catalog-real.stdout.txt) من حزمة E1.c: بند `OBS-REFERENCE-STATE-001` ومصدران خامان، manifest والبند. الفهرس مستقل عن مجموعة الاختبار، ويحفظ المواقع والمستندات وحقولها الأصلية. الأنواع المتقدمة والخصائص غير المعروفة تمثَّل للقراءة دون تفعيل أو حكم صلاحية. تبقى مؤشرات التحقق والتأهيل NOT_RUN والثقة NOT_EVALUATED، حتى إن تضمنت البيانات الخام ادعاءات QUALIFIED أو PASS.

يحفظ read_set_hash بصمة بايتات **مجموعة القراءة المحددة فقط**، والاختيار الصريح ظاهر في الناتج. تبقى candidate_hash وconfig_hash وinputs_hash وinputs.catalog الحاكم null حتى E2. بصمات المصدر ومجموعة القراءة ليست توقيع ناشر أو CP/JCS أو قبولًا حاكمًا. النقل JSON واحد بترميز UTF-8 وسطر أخير؛ صيغة text ملخص. حد جسم الفهرس 64 MiB، وحدود الإدخال الأصلية محفوظة؛ هذا ليس تأهيل موارد T15.

## الفرق والبصمات

- المرشح: **13 → 33 ملفًا**؛ 20 ملفًا جديدًا، منها 16 schema وملفا القفل/الفهرس وcatalog.py واختباره.
- البروتوكول الداخلي: **1 → 2**؛ metadata محفوظة، ونقل القراءة مضاف؛ لا تغيير في مخططات contract.1 الأصلية.

[SOURCE_PIN.json](SOURCE_PIN.json) يربط الملفات الخام ببصماتها. [PREFLIGHT.json](PREFLIGHT.json) يحفظ 10 نسخ سابقة و301 مدخل محمي، ويثبت غياب المسارات الجديدة قبل الإنشاء. يحفظ EVIDENCE_CHECKS روابط الفروق للملفات القديمة والجديدة والحالة السابقة واللاحقة. تبقى الحزمة المرجعية/الافتراضية 1.2.0 والمرشح 1.3.0 والعقود وأدلة E1.a/b/c محفوظة. لا commit أو push أو نشر أو ترقية أو تبنٍّ.

صُححت [أداة تجميع إيصال الحفظ](FINALIZATION_RECOVERY.json) لتستخدم SOURCE_PIN السابق ذي الملفات الـ13 كاملةً؛ AFTER السابق يسرد الملفات المسلّمة المتغيرة والجديدة فقط. ثبتت جميع بايتات الحالة السابقة وبصمتها الأصلية؛ لم يتغير المرشح أو الدليل السابق ولم تعد الاختبارات الناجحة.

مصادر النقل التقنية: [توثيق Python JSON](https://docs.python.org/3.12/library/json.html#json.dumps)، و[JSON Schema 2020-12 Core](https://json-schema.org/draft/2020-12/json-schema-core#section-8.2.3.1). هي مراجع تنسيق ونقل؛ السلطة على نطاق المشروع للتوجيه الحالي والعقود المحلية.
