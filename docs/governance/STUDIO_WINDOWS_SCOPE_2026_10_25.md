# قرار نطاق التوزيع — Windows

**السلطة:** توجيه المالك الصريح في2026-10-25: «لا داعي لدعم macOS ولا حتى Linux اذا كان العمل سيضيف تعقيدا كبيرا».

يتطلب دعم النظامين تغيير محوّل Windows Job Object ومشغّل Python ذي مسار بيئة Windows المجمدين في E3. لذلك يُحصر مرشح T38 الحالي وملف قبول T37–T40 الناتج في **Windows AMD64 / CPython3.12 / Node24.11 / Microsoft Edge**.

| السابق | اللاحق |
| --- | --- |
| T38 يشترط تجارب Windows/Linux/macOS | T38 يشترط Windows فقط؛ Linux/macOS: OUT_OF_SCOPE_BY_OWNER |
| تعذر WSL وغياب macOS عائقان للقبول متعدد الأنظمة | يبقى سجل المحاولات محفوظًا؛ النظامان لا يحجبان قبول نطاق Windows |
| تغييرات محوّلات أنظمة إضافية مطلوبة | لا تعديل على محوّلات E1–E4 المجمدة ولا إضافة محوّلات أنظمة أخرى |

بقية الشروط محفوظة: عتبات أداء T37، تغطية Backend، تجربة تثبيت Windows المعزولة، localhost والرموز المتغيرة، الفصل بين Draft والمرجع، المراجعة المستقلة T39، وتوقيع المالك T40 قبل النشر العام. هذا القرار لا يغير مرجع1.2.0 أو العقود البرمجية أو يمنح جاهزية إنتاج.
