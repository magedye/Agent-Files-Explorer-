# مراجعة الرأي المرفق بشأن خطة تحديث Studio

**التاريخ:** 2026-10-22. **النطاق:** تقييم الملاحظات وتصحيح وثيقتي التخطيط فقط.  
**نوع المراجعة:** مراجعة ذاتية مدعومة بالمصادر في سياق إعداد الخطة نفسه؛ ليست مراجعة الإصدار المستقلة T39، ولا موافقة بدء أو قبول إصدار.  
**الناتج:** [الخطة r2](../plans/STUDIO_FULL_PROJECT_UPGRADE_AR.md) و[قائمة المهام r2](../plans/STUDIO_UPGRADE_TASKS_AR.md).  
**حفظ الحالة السابقة والفروق:** [إيصال المراجعة](../evidence/studio-plan-review-2026-10-22/README.md).

## 1. الحكم

الرأي المرفق مفيد في تجزئة العمل وتعيين المسؤوليات ومركزة القرارات وبدء اختبارات الشاشات مبكرًا. بعض تصحيحاته يضيف سياسة أو يغير عقدًا قائمًا؛ لذلك لم يعتمد حرفيًا. صُححت الخطة حيث دعمت المصادر الملاحظة، وسجلت المقترحات الجديدة كقرارات مفتوحة، مع حفظ المتطلبات المعتمدة.

المراجع: [Studio](../specs/aghr-rc3/STUDIO_SPECIFICATION.md)، خاصة §§44–48، و[AGHR rc.3](../specs/aghr-rc3/AGHR_REFERENCE.md)، خاصة §§7 و11 و14، و[بوابات العقود](../contracts/aghr-rc3/ACCEPTANCE.md)، و[بروتوكول الأدلة والثقة](../contracts/aghr-rc3/PROTOCOL.md). المرفق رأي مراجعة؛ ليس مصدرًا أعلى من هذه العقود أو تعليمات المالك.

## 4. التقدير الزمني ونقطة البدء

لا تكفي المراجعة لتأكيد 14–18 أسبوعًا بدل 12–16. أزيل التعامل مع الإجمالي الأولي كتقدير صالح للالتزام؛ الإجمالي NOT_ESTIMATED حتى T01 وعينة T11a. تسجل العينة 50 معرفًا فريدًا من فئات الجرد الـ15 مع وقت العمل والغموض والقرار، ويعاد تقدير الـ1,558 الباقية حسب الفئة. دفعات T11b لا تتجاوز 50 وحدة أو نحو خمسة ملفات أو جلسة مركزة، وتصغر عند التعقيد؛ عددها النهائي ينتج من هذا القياس.

الخطة المقترحة تبدأ T00 → T01 عند توجيه بدء التنفيذ، ثم محرك/مصدر فعليان وعرض Phase 0 و`sentinel`، ثم SEC-001. لا تفترض جاهزية محرك أو مضيف أو منحة أو مراجع لمجرد وجود خطة لهم.

## 5. حدود هذه الدفعة

تغييرات في الخطة وقائمة المهام وموضع الاستئناف، مع هذا التقرير وإيصال قبل/بعد فقط. لم تتغير تعريفات العقود أو المواصفات المعتمدة، ولم يبدأ T00 أو SEC-001 أو تجارب المضيفين أو الترحيل أو نشر مرجع. بقي 1.2.0 مرجعًا وافتراضيًا و1.3.0 مرشحًا؛ سجل الجرد لم يراجع أو يعتمد بهذه الدفعة.
