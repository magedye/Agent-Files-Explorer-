## معايير الصدق السبعة — بوابات مستقبلية لا نتائج منجزة

تبقى الفحوص مطلوبة ولا تُعفى؛ نجاحها في نطاق النواة المحلي موثق منفصلًا عن تأهيل Codex وAntigravity. الفحوص التشغيلية لكل مضيف غير مختبر تبقى **REQUIRED / NOT_RUN / NOT_WAIVED**.

1. لا VERIFIED دون دليل تنفيذ.
2. لا PASS لمعرف UNKNOWN_ID.
3. لا PASS لمخرجات فارغة.
4. استهلاك task_criteria في التحقق، وليس قبول الوسيط فقط.
5. الفصل بين BLOCKED وNO_SKILL_MATCH.
6. لا HOST_SIGNAL دون إشارة المضيف الفعلية.
7. إبطال التأهيل عند تغير الإصدار؛ مع ربط النطاق والمحتوى أيضًا.

تغطي السيناريوهات الثمانية: تسلسل مهارات لميزة، مهمة بسيطة، تداخل مهارتين، مثبتة غير متاحة للجلسة، صلاحيات مرفوضة، تحميل ثم فشل تنفيذ، طلب عربي ومحفز إنجليزي، ودرس يتحول إلى مقترح تعليمات دون ترقية سياسة تلقائية.

## شروط البدء والإغلاق

يلزم عند البدء: قبول المالك لهذه الخطة، بصمات المصدر والعقود، وتحديد المضيف/الإصدار/النطاق وقناة الرصد الفعلية. غياب قناة رصد يمنع ادعاء تأهيل ذلك المضيف؛ لا يستبدل بمحاكاة. تشغيل موفر خارجي أو تكاليفه يخضع للتفويض المتاح حينها.

مخرجات التسليم: مصفوفة مطلب→دالة→اختبار→أصل دليل، فهرس CLI3 وأكواد خروجه، قبل/بعد وبصمات، وتقارير منفصلة للمحرك ولكل مضيف. لا يعد نجاح الوحدة قبولًا مستقلًا أو إصدارًا. لا إغلاق لحواجز SEC-001 الحقيقية قبل مصدر مؤسسي موثق وبوابة GitHub مرصودة وeval مطابق ومراجعات حقيقية.
