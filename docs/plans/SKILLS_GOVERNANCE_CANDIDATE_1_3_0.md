## حدود التنفيذ

- المرشح وحده يتغير؛ المرجع وZIP وملف بصمته وملفات INBOX الأصلية محفوظة.
- لا تثبيت أو تعديل لمهارات المستخدم أو الإضافات أو إعدادات المضيف، ولا خدمة أو مهارة توجيه جديدة.
- يكتشف المضيف مهاراته ويحملها؛ يقبل AGHR بياناته الصريحة دون مسح عام أو افتراض اكتمال الجرد.
- تبقى قواعد AGHR الـ47، ومنها AGHR-038، دون تغيير. التوجيه المقترح ممارسة تشغيلية في المرشح ضمن التفويض، وليس التزامًا عالميًا جديدًا.
- حالات الوحدة والسيناريو المحلي والتأهيل الأصلي وقبول الإصدار منفصلة. لا يمنح المحرك نفسه صلاحية أو اعتمادًا.
- 1.3.0 رقم مرشح لتوسعة اختيار المشروع وبيانات المضيف. تغير حالات أدوات المهارات موثق باعتباره أثر توافق يستلزم تحديث المستهلك؛ لا توجد واجهة legacy تعيد النجاح غير المثبت.

## معايير التسليم

**ملاحظة البوابة:** أول فحص كامل للحزمة نجح 319/319. أول npm test نجح 29/30 وفشل فقط لأن اختبار الحفظ كان يقارن مجموعة الملفات بإيصال 20 أكتوبر. جرى إثبات أن الأصول الثمانية لم تتغير وأن الإيصال الجديد يسجل 13 إضافة. التصنيف TEST_DEFECT / STALE_CONTEXT، والإصلاح محدود بمصدر إيصال الاختبار مع تشديد التحقق من الأصول ومن حذف بند. مراجعة ذاتية اكتشفت أيضًا اختيارًا زائدًا عند تغطية مهارة مركبة لمهارة سابقة؛ أضيف حذف الاختيار الزائد واختبار رجعي. الفحص النهائي يعاد ضد هذه التغييرات، ولا تمحو نتائجه سجل المحاولة الأولى.

1. الاختبارات المركزية والكاملة والسيناريوهات المحلية ناجحة ضد المرشح المحدد؛ تعلن الأعداد الفعلية وحدود الدليل.
2. المرجع وملفات توزيعه وINBOX والأجزاء غير المعدلة محفوظة ببصماتها، مع فرق نصي وقائمة إضافات وتعديلات وخرائط الحالات السابقة واللاحقة.
3. لا يعلن التحميل أو ملف metadata تفعيلًا أو تنفيذًا أو تأهيلًا أصليًا. وثائق Codex وAntigravity تسجل NOT_RUN أو NOT_OBSERVABLE حيث لم يتوفر الدليل؛ الاختبارات الاصطناعية لا ترفع هذه الحالات.
4. المرشح CANDIDATE_FOR_REVIEW؛ قبول الإصدار NOT_GRANTED، والمراجعة المستقلة NOT_PERFORMED. يظل افتراضي التطبيق والمرجع 1.2.0.
