## 1. الهدف والنطاق (Purpose & Scope)

- الأدلة التقنية وشروح المطورين (`Developer Guides & Manuals`).
- المعاجم والمصطلحات التقنية (`Glossaries & Dictionaries`).
- الوثائق المساندة والأمثلة التوضيحية (`Examples & Supporting Docs`).
- نتائج القياسات والمقارنات المرجعية غير الملزمة (`Reference Benchmarks`).
