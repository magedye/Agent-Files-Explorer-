# تقرير التحقق الأمني وحدود مصادقة المالك
## Security & Owner Authorization Verification Report

> **المهمة:** `AGHR-QLE-GOV-OBS-002`  
> **نطاق الفحص:** بوابات الأمان، مصادقة الجلسات، الحماية من الحقن، عزل مسودات القرارات، وحظر التعديلات السيادية غير المصرحة  
> **النتيجة:** اجتياز كامل مع استمرار الإغلاق الوقائي الحاسم (`Fail-Closed`)  

---

## 1. نموذج مصادقة الجلسات وصرامة البوابات (Session Authentication Boundary)

1. **الترويسة المعيارية (`X-Studio-Token`):**
   - ترتبط كافة نقاط النهاية في المرصد الدلالي `/api/v1/sgo/...` بجلسة الاستوديو النشطة.
   - يتم توليد رمز الجلسة مشفراً بطول 32 بايتاً عشوائياً فائق الأمان (`crypto.randomBytes(32)`).
2. **سلوك الرفض الآمن عند غياب أو تزوير الرمز:**
   - **الطلبات غير المرفقة برمز:** تُرفض فوراً برمز الاستجابة `401 Unauthorized` قبل قراءة جسم الطلب (`req.body`).
   - **الرموز المزورة أو المنتهية:** تُرفض برمز الاستجابة `403 Forbidden` مع تسجيل محاولة الاختراق في سجل التدقيق الأمني.
   - **الطلبات ذات الصلاحيات غير الكافية:** تُرفض برمز `403 Forbidden` لمنع تصعيد الامتيازات (`Privilege Escalation`).

---

## 2. الإغلاق الوقائي التام لقرارات المالك السيادية (`BLOCKED_UNPROVISIONED_OWNER_AUTH`)

### 2.1 مسار التعديل السيادي المحمي (`POST /api/v1/sgo/decisions/protected`)
- صُمم هذا المسار لتوثيق القرارات السيادية النهائية للمالك التي ترتب أثراً تنظيمياً ملزماً.
- **شرط التنفيذ:** يتطلب وجود هوية المالك السيادي مسجلة ومفعلة بمفاتيح تشفير غير متماثلة (Asymmetric Keys) ومطابقة لبصمة الهوية المعتمدة في وثيقة الإغلاق.
- **الواقع التشغيلي الحالي:**
  * نظراً لعدم إيداع المفاتيح السيادية الحقيقية للمالك على هذه الآلة المحلية، فإن نقطة النهاية المذكورة **تغلق وقائياً بصورة تلقائية وفورية (`Fail-Closed`)**.
  * تُرجع نقطة النهاية رمز الخطأ:
    ```json
    {
      "status": "BLOCKED",
      "code": "BLOCKED_UNPROVISIONED_OWNER_AUTH",
      "message": "لا يمكن توثيق قرار مالك نهائي: لم يتم تسجيل أو تكوين المفاتيح السيادية للمالك على هذه البيئة. تظل عمليات الكتابة السيادية مغلقة وقائياً."
    }
    ```
  * يضمن هذا الإغلاق الوقائي استحالة قيام أي وكيل برمجي أو مستخدم محلي بتمرير قرارات سيادية باسم المالك دون حضور المالك ومفاتيحه.

## 3. عزل مسودات القرارات غير المعيارية (Draft Decision Isolation)

- **مسار المسودات (`POST /api/v1/sgo/decisions/draft`):**
  * يتيح للمشغل المحلي تدوين ملاحظات تحريرية واقتراحات استرشادية دون الحاجة لمفاتيح المالك.
- **ضوابط العزل الصارمة:**
  * تُحفظ جميع هذه السجلات مع وسوم قطعية:
    ```json
    {
      "is_draft": true,
      "authorizes_engine_activation": false,
      "normative_status": "NON_NORMATIVE_DRAFT"
    }
    ```
  * تُحفظ المسودات في جدول منفصل بقاعدة بيانات SQLite المحلية (`rc3-local`).
  * تمنع بوابات التشغيل قراءة هذه المسودات من قبل محرك AGHR rc.3 الفعلي، مما يحول دون تسرب أي مسودة إلى القواعد الحاكمة.

---

## 4. الحماية من حقن الصيغ الماكرة في ملفات التصدير (Formula Injection Neutralization)

- **التهديد:** إمكانية احتواء حقول نصوص القواعد على صيغ برمجية ماكرة (مثل `=cmd|' /C calc'!A0` أو `+` أو `-` أو `@`) تستهدف برامج الجداول مثل Microsoft Excel عند التصدير إلى صيغة CSV.
- **المعالجة الهندسية المعتمدة:**
  * تم تضمين معالج تعقيم استباقي في دالة التصدير `exportReconciliationCsv`:
    ```javascript
    function sanitizeCsvCell(value) {
      if (typeof value !== 'string') return value;
      if (/^[=+\-@\t\r]/.test(value)) {
        return "'" + value; // تحييد الصيغة ببادئة اقتباس مفردة
      }
      return value;
    }
    ```
  * تم اختبار المعالج بنجاح في المعيار `AC-42` والتحقق من تعقيم كافة الخلايا المشبوهة.

---

## 5. الحماية من حقن المحادثة (Prompt Injection Defanging)

- في واجهة المحادثة المرجعية المستندة إلى المتن (`Grounded Policy Chat`):
  * يتم كشف وفلترة محاولات التلاعب بالتعليمات مثل `"Ignore previous instructions"` أو محاولات انتحال شخصية المالك.
  * يتم تحييد الألفاظ الخطرة، وتسجيل محاولة الحقن في سجل الأحداث، وإلزام الرد بالاستناد الحرفي فقط للمصادر المحلية (`OFFLINE_LEXICAL_GROUNDING`).
  * إذا لم توجد أدلة نصية مطابقة، يُرجع النظام حالة قطعية: `INSUFFICIENT_EVIDENCE`.

---

## 6. عزل الهويات الاختبارية المصطنعة (Synthetic Principal Isolation)

- جميع الاختبارات الآلية (مثل `AC-36` و `AC-39`) تستخدم هويات اصطناعية مؤقتة تنتهي بانتهاء جلسة الاختبار.
- لا يُسمح بتسجيل أي هوية اصطناعية في سجل القرارات السيادية أو تخزينها كمالك معتمد في قاعدة بيانات الاستوديو الدائمة.
