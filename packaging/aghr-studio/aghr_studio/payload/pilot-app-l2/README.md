# pilot-app-l2

Actual isolated sandbox application for T34 / L2 instructions.

Data are seeded sandbox business records, not production customer data.
The sole selected host is aghr-local-process. Native Codex/Antigravity remain NOT_RUN.
GPG commit signing is unsigned with owner-approved warning. Local CI job receipts use a separate ephemeral Ed25519 key; this is not a GPG identity or release signature.
Candidate documents are operator-authored; Studio writes only its isolated Draft database.
Canonical project state is written only by the local post-merge CI publisher.
