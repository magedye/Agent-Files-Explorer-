# بوابات المرحلة 0 وما يليها

**التاريخ:** 2026-10-22. تعريف العقود `COMPLETE_FOR_IMPLEMENTATION_REVIEW`، والمرحلة العامة `PHASE_0_IN_PROGRESS`. التقديرات في خطة المنتج أولية. اكتمال التعريف لا يمنح بوابات التشغيل حالة نجاح.

## تسلسل العمل ومعيار الانتقال

| البوابة | المخرج | معيار القبول | الوضع بعد استكمال التعريف |

| P0-B | API كامل | 58 عملية أصلية وsubmit موثق، أنواع كل الطلبات والأجوبة والأخطاء وWS، رفض مرشح اللغة والهوية المزورة | تغطية وتعريف مكتملان؛ إنفاذ HTTP/التفويض `REQUIRED / NOT_RUN / NOT_WAIVED` |
| P0-C | SQL | تطابق الكتل الست، إنشاء 12 جدولًا في الذاكرة، قيود الموافقة والتأهيل | PASS محلي في الذاكرة؛ لا قاعدة دائمة |

## تتبع الالتزامات إلى بواباتها

| الالتزام | دليل محلي ممكن الآن | الدليل التنفيذي الإلزامي اللاحق |
| --- | --- | --- |
| C1 | فصل المرجعية عن العقود والفهرس والأدلة | فحوص حدود الطبقات والسلطة والموافقات |
| C2،C3 | غياب مسارات كتابة state/evidence من مسودة API | رقابة الكتابة ومسار PR وناشر CI وعدم تغير بايتات المصدر |
| C4 | لا مرشح لغة في عقد مجموعة التعليمات | ثبات الانطباق عند تبديل اللغة وشارة الترجمة |

| C6 | قيم impact.evidence البنيوية | Calibration مع CP وeval ناجح ودلتا وموافقة |
| C7،C8 | بنية الملاحظة والاكتشاف المنفصلين | دليل مضيف وثلاثة مسارات UI وإيقاف الفشل |

| C11 | رفض بنيوي لبعض تقارير النجاح الناقصة | سبعة فحوص صدق وثمانية سيناريوهات فعلية منفصلة عن تأهيل Codex وAntigravity |
| C12 | حدود موثقة في القالب | فرض فعلي على الزمن والذاكرة وشجرة العمليات، مخرجات جزئية وحالة تجاوز صادقة |

تفصل [معايير المحرك](ENGINE_ACCEPTANCE.json) الفحوص غير البنيوية. فحص العقد المحلي ليس اختبار محرك، ولا اختبار API أو متصفح، ولا تأهيل مضيف، ولا مراجعة مستقلة. تبقى البوابات التنفيذية غير المنفذة مطلوبة وغير متنازل عنها؛ الأرقام 90% و85% في رأي المراجعة تقديرات وليست مقاييس قبول.
